# 引き継ぎ書(IDPA 統合プロジェクト)

> **状態: 作業中**(このファイルはプロジェクト完了時に完成させる。進行中の詳細は [worklog.md](worklog.md) を参照)

## プロジェクト概要

- S2MFD(太陽平均場ダイナモコード)に、IDPA リポジトリの遺伝的アルゴリズム(GA)パラメタ推定層を `S2MFD.inference` サブパッケージとして統合する。
- 手法の出典: 清水悠矢 修士論文(2025年度・名古屋大学)/ Shimizu & Hotta 2026, ApJ 996, 102。
- 実施計画・決定事項: [2026-08-19_integration_design.md](2026-08-19_integration_design.md)

## 完成時に記載する項目(プレースホルダ)

1. 新しい使い方(CLI / Python API)
2. 旧 IDPA → 新モジュール対応表
3. 修正したバグ一覧(本体・GA 層)
4. 意図的に挙動を変えた点(出力タイムスタンプ修正など)と旧データとの互換性
5. 検証結果(twin experiment、J08 ベンチマーク)
6. 残課題と論文5.1章の将来課題との対応
   - 推定区間の連続接続(前区間の終状態を次区間の初期条件へ)
   - 蝶形図(表面黒点分布)の適応度への利用
   - u0・s0 同時推定
   - 時間変化関数(sin級数)・適応度関数の改良
   - ダルトンミニマム等の急変期の再現精度
   - (コード側)移流スキームの風上化、potential BC 高次モードのエイリアシング、time_marching の高速化
