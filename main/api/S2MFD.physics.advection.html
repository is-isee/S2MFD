advection

S2MFD.physics.advection(Bph, Aph, RR, sinTH, urr, uth, drr2_, dth)[source]

Calculate the advection terms of the magnetic field.

Parameters:

  • Bph (numpy.ndarray) – Longitudinal magnetic field

  • Aph (numpy.ndarray) – Longitudinal vector potential

  • RR (numpy.ndarray) – Radial coordinate

  • sinTH (numpy.ndarray)

  • urr (numpy.ndarray) – Radial velocity

  • uth (numpy.ndarray) – Colatitudinal velocity

  • drr (numpy.ndarray) – Radial grid spacing

  • dth (numpy.ndarray) – Colatitudinal grid spacing

Returns:

  • Bph_adrr : Radial advection of Bph

  • Bph_adth : Colatitudinal advection of Bph

  • Aph_adrr : Radial advection of Aph

  • Aph_adth : Colatitudinal advection of Aph

Return type:

tuple of numpy.ndarray
