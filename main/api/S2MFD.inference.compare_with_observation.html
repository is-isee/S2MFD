compare_with_observation

S2MFD.inference.compare_with_observation(obs, index_start, index_end, sn_sim, ts_sim, uu0_sim, so0_sim, params, mode, output_dir, alpha=0.9)[source]

推定結果の比較プロットと数値結果を output_dir に保存する。

Parameters:

  • obs (observations.Observations) – 観測時系列

  • index_start (int) – 推定窓のインデックス範囲

  • index_end (int) – 推定窓のインデックス範囲

  • sn_sim (numpy.ndarray) – シミュレーションの黒点数プロキシ時系列と時刻 [s]

  • ts_sim (numpy.ndarray) – シミュレーションの黒点数プロキシ時系列と時刻 [s]

  • uu0_sim (numpy.ndarray) – 各出力時点での u0, s0 振幅

  • so0_sim (numpy.ndarray) – 各出力時点での u0, s0 振幅

  • params (dict) – 推定されたゲノム

  • mode (str) – ‘u0’ or ‘s0’

  • output_dir (str) – 保存先ディレクトリ

  • alpha (float) – 適応度の重み

Returns:

{‘cc’: 相関係数, ‘nmse’: NMSE, ‘eva’: 適応度}

Return type:

dict
