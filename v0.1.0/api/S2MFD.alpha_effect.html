alpha_effect

S2MFD.alpha_effect(Bph, Aph, rr, ibase, so, alpha_type)[source]

Calculate the alpha effect.

Parameters:

  • Bph (numpy.ndarray) – Longitudinal magnetic field

  • Aph (numpy.ndarray) – Longitudinal vector potential

  • rr (numpy.ndarray) – Radial coordinate

  • ibase (int) – Radial index for the base of the convection zone

  • so (float) – Source term coefficient

Returns:

Aph_sour – Source term due to alpha effect

Return type:

numpy.ndarray
