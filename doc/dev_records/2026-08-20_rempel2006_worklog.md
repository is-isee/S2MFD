## 1. ユーザーの要求仕様

1. 角運動量と質量 (音速抑制法を使うので ∫(ρ0 + ζ²ρ1) dV) を
   **machine precision で保存**すること
2. 全エネルギーは保存できないので、**変化をよく監視できる**ようにすること
3. **境界から保存量が出ていかない**ように注意すること (人工粘性も物理も)
4. 実装後も **kinematic dynamo の機能を残す**こと
5. 人工粘性で散逸した運動エネルギー・磁場エネルギーを
   **エントロピーの式に足す**のを忘れないこと

## 3. 設計上の中心的な判断

### 3.1 保存量に Ω₀ を含めない (齋藤 2024 の定式化)

```
保存量   q_L  = ρ0 r⁴ sin³θ · Ω1          <- 摂動のみ
フラックス F  = ρ0 r⁴ sin³θ · (Ω0+Ω1) v   <- 全体を運ぶ
```

Ω₀ は定数なので両者は**解析的に等価**。しかし保存量に Ω₀ を含めると、
大きさ ∝Ω₀ の数に ∝Ω₁ の増分を毎ステップ加えることになり、Ω₁ の相対精度が
eps·(Ω₀/Ω₁) に落ちる。剛体回転から出発すると Ω₁/Ω₀ → 0 なので初期ほど悪い。

数値実験 (96×96、純移流、剛体回転から出発):

| 形式 | 総角運動量 (厳密に 0 のはず) | Ω₁ の相対誤差 |
|---|---|---|
| 素朴形 `ρ0r⁴sin³θ(Ω0+Ω1)` | 7.0e+24 | 1.0e-10 |
| 齋藤形 `ρ0r⁴sin³θ·Ω1` | 2.3e+16 (丸め1単位) | **2.0e-14** |

テスト `test_perturbation_form_beats_total_form` で固定。

### 3.2 保存形と移流形のずれ

保存形は移流形 ρ₀D(ϖ²Ω)/Dt に対して `-Ω₀ϖ²∇·(ρ₀v)` だけ余分な項を持つ。
質量流束が離散的に非発散なら消えるが、音速抑制法では
`∇·(ρ₀v) = -ζ²∂ρ₁/∂t` なので厳密にはゼロにならず、しかも係数 Ω₀ で
増幅される。圧縮性のある速度場で測ると、この項が保存形の右辺の **98%** を
占めた。

Rempel は角運動量方程式を**移流形**で書いており (2005 式 4)、これは
「厳密な保存」と「圧縮性誤差への Ω₀/Ω₁ 倍の感度」のトレードオフとして
まっとうな判断である。

対応として `consistent_advection=True` オプションを用意した。連続の式と
同一の質量流束の面値に比角運動量 ϖ²(Ω₀+Ω₁) の面値を掛ける形で、Ω が
一様なら角運動量方程式が質量方程式に帰着する (free-stream preservation)。
既定は齋藤形のまま。

### 3.3 厳密な保存が必要なのは質量と角運動量だけ

球座標では動径・子午面方向の運動量は幾何学的な源項 (遠心力・曲率) を
必然的に持つので保存量ではない。軸対称系で厳密に保存するのは回転軸まわりの
角運動量だけで、これは離散化でも厳密に保てる。齋藤コードも同じ構成
(`qqt2`, `qqt3` には源項があり、`qqt4` にはない)。

### 3.4 散逸のエントロピーへの還元

応力から Q = Σ(1/2)E_ik R_ik を別途離散化するのではなく、
**「運動量方程式が奪った分をそのまま渡す」**形にした:

```
Q = -(v_r·dq_mr + v_θ·dq_mt + (Ω0+Ω1)·dq_om)/(r²sinθ)   ← 散逸項のみ
∂s1/∂t += (γ-1)/p0 · Q
```

これなら離散化がどうであれエネルギー移送が厳密で、係数はちょうど 1 になる。
しかも Rempel の Q の定義そのもの (境界フラックスがゼロなので部分積分の
表面項が消え、Q は「レイノルズ応力が流れにした仕事の符号反転」に等しい)。
粘性項は正の加熱、Λ 効果は負の加熱になり、原論文の記述
「Q は粘性散逸による加熱項と Λ 効果による冷却項を含み、後者が一般に支配的」
がそのまま再現される。

### 3.5 人工拡散は保存形の枠組みに乗せる

齋藤コードにも人工粘性 `artdif.f90` があるが `mhd.f90` で呼び出しが
コメントアウトされている。理由は明白で、本体と**異なる保存量**
(`r³sin²θ·Ω1`、ρ₀ を含まない) に対して定義されており、幾何因子を
フラックスの外側に掛けているため、有効にすると角運動量保存が壊れる。

本実装は **拡散対象はプリミティブ変数、フラックスは保存量と同じ
ヤコビアンを掛けた形** にした:

```
F^r = -(1/2) c Φ · ρ0 r⁴ sin³θ · (Ω1[i] - Ω1[i-1])
```

物理粘性の `ν ∂_rΩ1` が `(1/2)cΦ ΔΩ1` に置き換わっただけなので、面で1回
計算して2セルで共有 → telescoping、境界面はリテラル 0.0、拡散されるのは
Ω1 そのもの、が同時に成り立つ。

保存量 q_L を直接拡散させないのは、極近傍では q_L の勾配が Ω1 ではなく
幾何因子 sin³θ の変化に支配される (第1セルと第2セルで 8 倍違う) ため。

## 4. 発見したこと

### 4.1 Rempel の下部境界条件は系を閉じない

Rempel 2005 §2.6:

> "At the bottom boundary (r = 0.65 R⊙) we enforce a uniform rotation;
> the top boundary is stress-free for the angular velocity (R_rφ = 0)."

つまり下部境界は **Ω₁ = 0 の Dirichlet 条件**であり、固定 Ω のリザーバとして
粘性フラックスがそこを通る。Rempel 自身が「物理的なタコクラインではなく
人為的な装置」と明言している:

> "we do not include a sophisticated theory for the tachocline but force a
> tachocline through a uniform rotation boundary at r = 0.65 R⊙. As a
> consequence the tachocline is a viscous shear layer between the convection
> zone and the lower boundary condition."

したがってユーザー要求「境界から保存量が出ていかないように」と Rempel の
設定は**そのままでは両立しない**。両方を提供することにした:

- `angmom_bottom_bc='stress_free'` — 閉じた系。∫q_L が machine precision で保存
- `angmom_bottom_bc='uniform_rotation'` — Rempel 再現。境界フラックスを
  RK2 と同じ重みで積算し、`ΔL = ∫(境界フラックス)dt` が machine precision で
  成立することを検証する (漏れを許すのではなく、漏れを厳密に勘定する)

実測: ΔL/L = 2.14e-4 の流入に対し、収支残差は相対 9.8e-14。

### 4.2 Rempel は人工粘性を使っていない

両論文を全文検索したが、artificial viscosity / hyperdiffusion / filter の
記述は一切ない。散逸はすべて物理的な ν_t, κ_t, η_t と、**MacCormack の
交互風上/風下差分に内在する数値散逸**による。

これは実装上決定的で、MacCormack が音波に対して持つ暗黙の散逸は

```
(1/2) c_eff Δx ≈ 0.5 × 2.56e5 × 3.64e8 ≈ 5e13 cm²/s
```

であり、物理的な乱流粘性 ν_t = 3e12 の **15 倍**にもなる。S2MFD の
SSP-RK2 + 中心差分は数値散逸をまったく持たないので、同等の散逸を
明示的に入れなければならない。

### 4.3 上部境界は 0.985 R⊙ では解けない

Rempel は r = 0.65 - 0.985 R⊙ を使うが、本実装では 0.985 R⊙ は不安定。
Rempel (2005) のポリトロープは 1.0007 R⊙ で密度ゼロに達するので、
0.985 R⊙ では ξ = 0.039 まで落ちて成層が破綻寸前になる。

実測 (0.30 年積分):

| 上部境界 | nx | dr/H_p (上端) | 結果 |
|---|---|---|---|
| 0.985 R⊙ | 64 | 0.66 | 発散 |
| 0.985 R⊙ | 128 | 0.35 | 発散 |
| **0.96 R⊙** | 64 | 0.28 | **安定** |
| 0.96 R⊙ | 128 | 0.14 | 安定 |
| 0.95 R⊙ | 64 | 0.23 | 安定 |

解像度を上げても直らないので、これは離散化の分解能ではなく**成層の
急峻さそのもの**の問題。齋藤 (2024) が 0.96 R⊙ を採用しているのも
同じ事情と考えられる。既定を 0.96 R⊙ にした。

### 4.4 潰したバグ

いずれも推測ではなく、物理項を一つずつ落とす切り分けで特定した。

**(a) エントロピーに人工拡散を掛け忘れていた**

s1 は中心差分で移流されるだけで散逸を持たないため格子ノイズが減衰せず、
状態方程式 `p1 = p0(γρ1/ρ0 + s1)` を通して圧力に乗り、ρ0 が小さい
対流層上部で `ρ0⁻¹∂_r p1` として巨大な加速に化ける。その速度がさらに s1 を
かき混ぜるので正のフィードバックになる。赤道近傍・上部対流層から壊れた。

**(b) レイノルズ応力の二重計上**

`angular_momentum_rhs` が応力を `dq_om` と `dq_stress` の両方に書いており、
呼び出し側でも `dq_om += ds_om` していたため、粘性と Λ 効果が 2 倍に
なっていた。**見た目には「それらしい」差動回転が出るので気付きにくい。**
境界フラックスの収支がちょうど 2 倍ずれることで発覚した。

**(c) 下部境界条件が実質無効だった**

`angmom_bottom_bc='uniform_rotation'` は Ω1=0 のゴーストを設定していたが、
境界フラックスを一律ゼロ化していたため何の効果もなく、`stress_free` と
ビット単位で同じ結果になっていた。

**(d) 拡散項の CFL に安全率を掛け忘れていた**

κ を 100 倍にした設定が静かに壊れていた。人工拡散自体も陽解法なので
CFL に算入するようにした。

### 4.5 CFL は音速・アルヴェン速度・流れの 3 つで決まる

音速抑制法が遅くするのは**音波だけ**で、アルヴェン速度は変わらない。
磁場が上部対流層 (ρ0 が小さい) に達すると、ζ をいくら上げても
アルヴェン速度が dt の下限を決める。実測 (128×128、B_φ=1.28e4 G):

| RSST | 実効音速 | v_A (最大) | dt | 律速 |
|---|---|---|---|---|
| ζ=100 | 2.6e5 | 8.4e3 | 132 s | 音速 |
| ζ=300 | 8.5e4 | 8.4e3 | 395 s | 音速 |
| ζ=1000 | 2.6e4 | 8.4e3 | 1315 s | 音速 |

磁場がタコクライン (ρ0 が大きい) にある限りアルヴェン速度は効かないが、
上部対流層 (ρ0=7.4e-3) に達すると v_A ≈ 3.3e4 になり ζ≈1000 で切り替わる。

参考: kinematic ダイナモの dt は `defaults.py` (J08) で 1.45e5 s = 1.68 日
(拡散律速)、`hotta10.py` で 2.29e3 s。力学モード (ζ=100) の dt=132 s は
J08 比で 1100 倍、hotta10 比で 17 倍のステップ数になる。

## 5. 未解決の課題 — 長時間積分の安定性

**現状、Rempel の物理パラメタ (ν_t = κ_t = 3e12 cm²/s) では 64×64 で
0.36 年程度で発散する。**

切り分けの結果:

| 条件 | 結果 |
|---|---|
| baseline (Rempel パラメタ) | 発散 |
| κ_t × 10 | **安定** |
| ν_t × 10 | **安定** |
| δ = -1e-4 (全域を亜断熱に) | **安定** |
| δ = 0 (完全断熱) | 発散 |
| Λ 効果 × 0.1 | 発散 (振幅依存ではない) |
| 緯度・動径解像度 2 倍 | 発散 (解像度の問題ではない) |
| 人工拡散なし | より早く発散 |

不安定モードは**格子スケールではなく 6-8 セルの解像された波**で、
上部対流層・赤道近傍から成長する。

原因は §4.2 の通り、**Rempel の MacCormack が持つ暗黙の数値散逸
(物理粘性の 15 倍) を我々が持っていない**こと。対流層が中立成層
(δ_conv = 0、Rempel 2005 case 1) だと復元力がないため、解像されたスケールの
モードが準中立になり、SLD は「解像された場には効かない」設計なのでこれを
抑えられない。

対応として SLD に `sld_floor` (部分的な風上化の下限) を導入した。
`floor=0` なら純粋な SLD、`floor=1` なら完全な Rusanov (1 次風上)。
Rempel のスキームが持つ暗黙の散逸に相当する量を明示的に入れるための係数で、
論文からの逸脱ではなく**異なる時間積分法を使うことの必然的な代償**である。

適切な `sld_floor` の値、あるいは ν_t/κ_t をどこまで上げるかは
スキャン中 (`results_rempel/scan.log`)。決まり次第、長時間緩和ランで
Rempel 図1 の差動回転 (Ω_eq-Ω_pole)/Ω0 = 0.27 と比較する。

### 5.1 今後の選択肢

1. `sld_floor` を上げて MacCormack 相当の散逸を入れる (実装済み、値を決定中)
2. ν_t/κ_t を Rempel より大きくして使い、その旨を明記する
3. 音響系だけを Rusanov 化した半風上スキームにする (未実装)
4. 亜断熱度 δ を Rempel の case 8-10 (δ_cz ≠ 0) 側にして復元力を持たせる

### 6.1 全球格子での Λ 効果の対称性

Rempel も齋藤も北半球のみを解くので傾き角 λ の符号を考える必要がない。
S2MFD は全球 [0, π] を解くため、そのまま使うと赤道対称性が壊れる。

q_L が偶関数であるためには F^r が偶、F^θ が奇でなければならず、
幾何因子 sin²θ が偶であることから Λ_rφ は偶、Λ_θφ は奇である必要がある。
振幅 L は cosθ に比例して奇なので、傾き角を λ·sgn(cosθ) として南半球で
符号を反転させるとこの条件を満たす (物理的にも傾きは両半球で鏡像になる)。

なお Rempel 2005 は「λ > 0 のときは n > 2 が必要 (極でレイノルズ応力の
発散が正則になるため)」と述べており、2006 の参照モデルは n=3。
齋藤コードの n=2 は λ=15° と組み合わせるとこの条件を満たさない。
