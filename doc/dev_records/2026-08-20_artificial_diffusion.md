# 人工拡散 (slope-limited diffusion) の実装で踏んだ罠

2026-08-20。ブランチ `feature/rempel2006`。

Rempel (2006) の再現作業で、**人工拡散だけで 4 つの独立した誤りを踏んだ**。
いずれも「計算は安定なまま、答えだけが静かに間違う」種類のもので、
テストや保存則チェックでは検出できなかった。同じ轍を踏まないための記録。

---

## 0. 最終的に採用した方式

**Rempel (2014, ApJ 789, 132) §2.1 の slope-limited diffusion**。
実装は R2D2 の `src/include/artdif_func.F95` と `src/all/artdif_spherical.F90`
に準拠している。

```
u_l = u_i + Δu_i/2
u_r = u_{i+1} - Δu_{i+1}/2

Δu_i = minmod_ε[ (u_{i+1}-u_{i-1})/2, ε(u_{i+1}-u_i), ε(u_i-u_{i-1}) ]

r     = (u_r - u_l)/(u_{i+1} - u_i)
Φ_h   = max[0, 1 + h(min(1,r) - 1)]        (r ≤ 0 なら 0。反拡散にしない)
f_{i+1/2} = -(1/2) c_{i+1/2} Φ_h (u_r - u_l)
```

| パラメタ | 値 | 出典 |
|---|---|---|
| `h` (`sld_fh`) | 2.0 | Rempel 2014 §2.1 / R2D2 `artdif_init.F90` |
| `ε` (`sld_ep`) | 2.0 | R2D2。ε=2 で MC リミタ |
| 特性速度 | `c = |v| + v_A + 0.3 c_s,eff` | R2D2 `cfl.F90` |
| CFL の速度 | `|v| + v_A + c_s,eff` (係数なし) | 同上 |

**性質**: 局所的に線形な場では左右からの再構成が面上で一致するので
`u_r - u_l = 0` となりフラックスが**厳密にゼロ**。格子スケールの振動では
リミタが傾きをゼロにするので `r = 1`, `Φ_h = 1` となり最大拡散
`(1/2) c Δx` が効く。`h > 1` なら `r < 1 - 1/h` で完全に切れる
(h=2 なら r < 0.5)。`h = 0` は 2 次 Lax-Friedrichs に一致。

## 罠 1: 散逸加熱を `u · dq/dt` で局所評価した

**症状**: 論文どおりのパラメタで 0.4 年程度で発散。人工拡散を強めても直らず、
`κ_t` や `ν_t` を 10 倍にすると安定化する。解像度を上げても直らない。
不安定モードは格子スケールではなく **6-8 セルの解像された波**。

**原因**: 散逸で失われたエネルギーをエントロピーに戻すとき、
「運動量方程式が奪った分」= `u · dq/dt` を使っていた。体積積分では
正しいが、局所的には発散の分だけずれる:

```
u dq/dt = -div(u F) + F·grad(u)
```

第1項は輸送で、体積積分すると境界だけに残る。第2項が**局所的な**変換である。
角運動量では `u = Ω₀ + Ω₁` で `Ω₀ ≫ Ω₁` なので、このずれは正しい値の
**Ω₀/Ω₁ 倍 (20〜100倍)** にもなり、しかも符号が空間的に振動する。
その結果エントロピー方程式に偽の双極子ができ、浮力を通じて計算を壊していた。

**対処**: 正しい局所形 `-F·∇u` を面フラックスと面での勾配から直接作る
(`conservative.add_flux_work`)。`Ω₀` は微分で消えるので偽の加熱が生じない。
離散化も面フラックスと面の勾配を組にしたので、拡散フラックス
`F = -κJ Δu/Δr` に対して各項が `+κJ(Δu/Δr)² ≥ 0` となり、
**散逸の正値性が離散レベルで保証される**。

これを直したら論文どおりのパラメタで安定になった。

## 罠 2: 「解像された場でも下限だけ残す」独自の後付け

**症状**: 安定にはなったが、差動回転が論文の 1/10 (0.024 対 0.27) で飽和。
初期条件を Rempel 相当にしても 1 年で落ちる。解像度を上げても、
亜断熱層の設定を変えても改善しない。

**原因**: Hotta+2017 の SLD に、私が独自に `sld_floor` を足していた。
「リミタが『解像されている』と判断してもその割合だけ Rusanov 型散逸を残す」
仕組みで、Rempel の MacCormack が持つ暗黙の数値散逸を補うつもりだった。

これは **Rempel 2014 の `Φ_h` と正反対**である。`Φ_h` は滑らかな領域で
拡散を**完全に切る**のに対し、`sld_floor` は強制的に**残す**。

致命的だったのは、**Rempel のモデルが「拡散を意図的に小さくした領域」に
依存している**ため:

| 領域 | 物理拡散 | 役割 |
|---|---|---|
| オーバーシュート層 | `κ_t` = 対流層値の **0.2%** (6e9) | エントロピー摂動を溜めて Taylor-Proudman を破る (Rempel 2005 の中心機構) |
| 放射層 | `ν_dif` = 対流層値の **2%** (6e10) | 下部境界の Ω₁=0 との間にタコクライン (粘性せん断層) を作る |

当初の設定 (`floor=0.1`, 音速の係数なし) では
`κ_SLD = (1/2)·0.1·c_s,eff·Δx = 4.3e12` で、**オーバーシュート層の 700倍、
放射層の 70倍**。対流層の物理拡散 3e12 すら上回っていた。
これでは低拡散領域が存在しないのと同じである。

**対処**: `sld_floor` を撤去し、Rempel 2014 の `Φ_h` をそのまま使う。

## 罠 3: 特性速度に音速をそのまま使った

**症状**: 罠 2 を直しても、差動回転は 0.037 で頭打ち。

**原因**: 特性速度を `|v| + c_s,eff` としていた。抑制後とはいえ音速は
流れより 2 桁速い (`c_s,eff ~ 2.6e5` に対し `|v| ~ 1e3` cm/s)。

**定常状態でエントロピー方程式の収支を項別に測って発覚した:**

```
背景勾配 (生成源)  5.94e-14 /s
移流              2.04e-15
熱伝導            7.54e-15
合計              5.92e-14   <- 釣り合っていない
```

物理的な項では生成源の **1.6% しか打ち消せておらず**、残りを人工拡散が
消していた。

**対処**: R2D2 に合わせて `c = |v| + v_A + 0.3 c_s,eff` とする。
CFL には係数なしの `|v| + v_A + c_s,eff` を使う。

効果:

| | 修正前 | 修正後 |
|---|---|---|
| 人工拡散/Q_Λ | 1.00 | 0.001 |
| \|s1\| | 1.4e-7 で飽和 | 増加継続 |
| 差動回転 | 0.024-0.037 で飽和 | 0.275 まで成長 (Rempel 0.27) |

## 罠 4: 球座標の幾何項 (ベクトル成分の基底の回転)

**症状**: なし。計算は安定なまま、子午面循環だけが少しずつ間違う。
ユーザーの指摘で気付いた。

**原因**: 球座標の基底ベクトルは θ に依存する:

```
∂ê_r/∂θ = ê_θ,   ∂ê_θ/∂θ = -ê_r
```

したがって `v_r` と `v_θ` をスカラーとして独立に拡散させるのは誤り。
θ 方向の掃引では

```
∂/∂θ (F_r ê_r + F_θ ê_θ) = (∂_θF_r - F_θ) ê_r + (∂_θF_θ + F_r) ê_θ
```

となり、成分が混ざる項が要る。

**対処**: 保存量にヤコビアンを吸収した本実装では、面フラックス配列を
そのままセル中心へ平均した形になる:

```
dq_mr += <F^θ_{v_θ}>
dq_mt -= <F^θ_{v_r}>
```

R2D2 の `artdif_spherical.F90` の `j1 == 1` ブロックと同じ。

**適用範囲**:
- r 方向の掃引には不要 (基底は r に依らない)
- `Ω₁`, `ρ₁`, `s₁` はスカラーなので不要
- 軸対称なので φ 掃引はなく、`B_φ` にも不要
  (R2D2 の `k1 == 1` ブロックに相当するものは要らない)

## 保存形との両立について

齋藤 (2024) のコードには人工粘性 `artdif.f90` があるが、`mhd.f90` で
呼び出しがコメントアウトされている。理由は明白で、本体と**異なる保存量**
(`r³sin²θ·Ω1`、ρ₀ を含まない) に対して定義されており、幾何因子を
フラックスの外側に掛けているため、有効にすると角運動量保存が壊れる。

本実装は **拡散対象はプリミティブ変数、フラックスは保存量と同じ
ヤコビアンを掛けた形** にすることで両立させた:

```
F^r = -(1/2) c Φ_h · ρ0 r⁴ sin³θ · (Ω1_r - Ω1_l)
```

物理粘性の `ν ∂_rΩ1` が `(1/2)cΦ_h ΔΩ1` に置き換わっただけなので、
面で1回計算して2セルで共有 → telescoping、境界面はリテラル 0.0、
拡散されるのは Ω1 そのもの、が同時に成り立つ。

保存量 `q_L` を直接拡散させないのは、極近傍では `q_L` の勾配が `Ω1` ではなく
幾何因子 `sin³θ` の変化に支配される (第1セルと第2セルで 8 倍違う) ため。

密度だけは音速抑制法の `1/ζ²` が発散全体に掛かるので、
`sld_diffuse_scaled` で係数付きの発散を取る (`ζ` が動径依存の場合に
`∫ζ²ρ1 dV` の保存が壊れないようにするため)。

## 教訓

1. **人工拡散の「強さ」は、モデルが依存する最小の物理拡散と比べること。**
   対流層の値と比べても意味がない。Rempel のモデルは対流層値の 0.2% まで
   落とした領域が本質なので、そこが基準になる。

2. **特性速度は「その変数が何で運ばれるか」ではなく、標準的な処方
   (流れ + アルヴェン + 係数×音速) に従うこと。**
   一度「Ω₁ と s₁ は音波で運ばれないから流速だけ」としたが、これは行き過ぎで、
   正しくは 3 つの和に音速の係数 0.1〜0.3 を掛ける。

3. **リミタに独自の下限を足さないこと。** `Φ_h` が「滑らかなら切る」設計に
   なっているのには理由がある。

4. **ベクトル成分を曲線座標で拡散させるときは基底の回転項を忘れないこと。**

5. **エネルギー変換率は局所形 `-F·∇u` で書くこと。** `u·dq/dt` は体積積分
   でしか正しくない。背景に大きな定数 (`Ω₀`) がある場合は特に危険。

6. **これらはどれも計算を壊さない。** 保存則テストも通るし、それらしい解も
   出る。**エントロピー方程式の収支を項別に測る**、**エネルギー交換項を
   論文の表と比べる**といった、答えの中身を見る診断がないと気付けない。
