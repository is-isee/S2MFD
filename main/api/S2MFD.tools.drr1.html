drr1

S2MFD.tools.drr1(qq, drr, dir)[source]

To calculate 1st order accuracy derivative in r direction

Parameters:

  • qq (numpy.ndarray, float) – Quantity to be differentiated (2D)

  • drr (float) – Grid spacing in r direction

  • dir (string) –

    ‘up’ or ‘dw’

    ’up’: dqq[i] = (qq[i] - qq[i-1])/drr (後退差分、i=1..N-1 に格納) ‘dw’: dqq[i] = (qq[i+1] - qq[i])/drr (前進差分、i=0..N-2 に格納)

    セル境界 i-1/2 の勾配を ‘up’ で作り、’dw’ で発散を取ると 保存形の2階差分になる (diffusion() での用法)。

Returns:

dqq – Differentiated quantity (2D)

Return type:

numpy.ndarray, float
