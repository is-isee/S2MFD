Usage

基本の実行

S2MFDでは、デフォルトのシミュレーションパラメタを用意しており、以下で実行できる。

import S2MFD
sim = S2MFD.run_simulation()

デフォルトのパラメタは Jouve et al., 2008 のFlux transport dynamoの動径磁場上部境界条件のものである。 run_simulation は実行後の S2MFD.Simulation オブジェクトを返す (磁場 sim.Bph, sim.Aph や時刻 sim.time にアクセスできる)。

出力は cfg.datadir (既定 data/) に、40日 (dtout) ごとの スナップショット data.NNNNNN.npz (Bph, Aph, time, n, nd, dt, uu0, so0) と、メタデータ (config.json, grid.npz, setup.npz, legendre.npz) が書かれる。

パラメタの変更

パラメタを変更するには、以下の二つの方法がある。

  1. パラメタファイルを用意する。

    S2MFD.run_simulation() の parameter_file 引数にパラメタファイルのパスを指定する。パスが存在すればそのまま(絶対パス・カレント相対)、存在しなければ S2MFD/ パッケージディレクトリ相対として解決される。

    import S2MFD
S2MFD.run_simulation(parameter_file='parameters/your_parameter_file.py')

    パラメタファイルは以下のように記述する。

    from S2MFD.parameters.defaults import *
m = 0

    S2MFD/parameters/defaults.py にはデフォルトのパラメタが記述されている。これを継承して、必要なパラメタを変更する。

  2. パラメタを直接指定する。

    パラメタサーベイをする場合などは、こちらで対応する。 S2MFD.Cfg クラスを読み込んだ後に、直接パラメタを指定する。

    import S2MFD
cfg = S2MFD.Cfg()
cfg.rey = 1400       # 基本量の変更
cfg.resolve()        # 派生量 (uu0 = rey*ett/RSUN など) を再計算
S2MFD.run_simulation(cfg=cfg)

    Note

    uu0 や so0 のような派生量は、基本量 (rey, cso, ett など) の変更後に cfg.resolve() を 呼ぶことで再計算される (S2MFD.Simulation の生成時にも自動で 呼ばれる)。派生量を直接代入した場合は、その値が優先され resolve() では上書きされない。

物理モデルの選択肢

背景場は文字列スイッチで選択する。未知の文字列は ValueError になる。 各選択肢が必要とするパラメタは S2MFD/setup.py の該当分岐を参照のこと (H10系のパラメタ例は parameters/hotta10.py にある)。

スイッチ

選択肢

意味

differential_type

‘J08’ / ‘H10’

差動回転プロファイル

diffusive_type

‘J08’ / ‘H10’

磁気拡散プロファイル

alpha_type

‘BL’ / ‘normal’ / ‘H10’

α効果 (BL, H10 は非局所型)

meridional_circulation_type

‘J08’ / ‘D99’ / ‘H10’

子午面流プロファイル

boundary_condition_type

‘vertical’ / ‘potential’

上部境界条件

Warning

振幅パラメタ (so0 等) の規格化は選択肢間で統一されていない (例: ‘BL’ と ‘normal’ で異なる係数が掛かる)。選択肢をまたいで振幅を 比較しないこと。

ランの継続 (リスタート)

cont_flag = True (既定) のとき、既存の datadir があると 最後のスナップショットから自動で再開する (「何も考えなければ続き」が仕様)。 再開時には既存の config.json と現在の設定の整合性が検査され、 物理・格子パラメタが食い違う場合はエラーになる (tend, dtout などの変更 = ランの延長は許容される)。新規にやり直す場合は別の datadir を指定するか、既存データを削除する。

時間依存パラメタ

子午面流振幅 uu0 と α効果振幅 so0 は、cfg に呼び出し可能な 属性を定義すると出力ステップごとに時間変化させられる。

cfg = S2MFD.Cfg()
cfg.uu0_of_time = lambda t: 700.0 + 100.0 * np.sin(2*np.pi*t / (22*365*86400))
S2MFD.run_simulation(cfg=cfg)

引数 t はシミュレーション時刻 [秒]、返り値は振幅である。 パラメタ推定 (Parameter Inference (GA)) はこの仕組みの上に構築されている。

解析スクリプト

ana/ に解析スクリプトがある。いずれもコマンドライン第1引数で データディレクトリを指定できる (既定 ../data/)。

python ana/ana.py data/                # 一括読み込み (対話解析の起点)
python ana/butterfly_diagram.py data/  # 蝶形図
python ana/sunspots_number.py data/    # 黒点数プロキシ時系列
python ana/J08_test.py data/           # Jouve+2008 ベンチマーク比較
python ana/check_profile.py parameters/hotta10.py  # 背景場プロファイル確認

数値の厳密さと速度

時間積分カーネルは既定で高速経路を使う。除算を逆数の乗算に置き換え、 numba の fastmath を有効にしているため、1 substep あたり倍精度 1 ULP 程度 (相対 ~2e-16) の丸めの違いが参照実装との間に生じる。磁気拡散を含む散逸系 なのでこの差は積分しても増幅せず、黒点数時系列の相関は 1.000000000000、 適応度は小数 10 桁まで一致することを確認している。

参照実装とビット一致させたい場合 (数値実験の再現性を厳密に確かめるとき等) は:

cfg = S2MFD.Cfg()
cfg.exact_arithmetic = True   # 約3倍遅いが参照実装とビット一致
S2MFD.run_simulation(cfg=cfg)

参照実装そのものは S2MFD.physics.time_marching_reference() として 残してあり、テスト (tests/test_kernel_equivalence.py) で 両者の等価性を常時検証している。
