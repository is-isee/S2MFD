# Rempel (2006) を S2MFD で再現する — 検討結果

- 日付: 2026-08-19
- 資料:
  - Rempel (2005) ApJ 622:1320 — 平均場の差動回転・子午面流モデル
  - Rempel (2006) ApJ 647:662 — ローレンツ力フィードバック付き磁束輸送ダイナモ (**本命**)
  - Hotta (2017) ApJ 845:164 — 人工拡散による散逸の評価と扱い
  - 齊藤崇太 修士論文 (千葉大 2024) — Rempel 2005 の再現、角運動量保存の記述
  - 齊藤コード (Fortran 1505行) — 保存形の動く参照実装
- ユーザー指定の要求仕様:
  1. **角運動量を machine precision で保存**
  2. **質量 ∫(ρ₀+ζ²ρ₁) を machine precision で保存** (音速抑制法のため ζ² 重み)
  3. **全エネルギーは保存しないので、変化をよく監視できるようにする**
  4. **境界から保存量を漏らさない — 人工粘性も物理と同じ扱いで**
  5. **人工粘性で散逸した運動・磁気エネルギーをエントロピー方程式に足す**
  6. **kinematic dynamo の機能は残す**

## 結論

**できます。しかも思ったより相性が良い。**

理由は3つ:

1. **S2MFD の誘導方程式は、既に Rempel 2006 の式 (6)(7) そのもの**です(下記 §1 で照合)。
   ダイナモ部分は新規実装がほぼ不要。
2. **齊藤コードと S2MFD は、格子・時間積分の流儀が一致**しています
   (セル中心格子・極をセル境界に置く・ゴーストセル・SSP-RK2 = TVD-RK2)。
   保存形の離散化をそのまま移植できる。
3. ご要望の **machine precision 保存は、齊藤コードで実証済みの手法**が使えます。

必要なのは「S2MFD の誘導ソルバ」に「齊藤コードの保存形流体ソルバ」を接続し、
Rempel 2006 が追加した**ローレンツ力・エントロピー方程式**を足すことです。

## 1. S2MFD の誘導方程式は既に Rempel 2006 と同一

照合した結果、**式の形が完全に一致**していました。

| Rempel 2006 | S2MFD の実装 | 一致 |
|---|---|---|
| −(1/r)∂_r(r v_r B_Φ) (6) | `Bph_adrr = -drr2(Bph*urr*RR,drr)/RR` | ○ |
| −(1/r)∂_θ(v_θ B_Φ) (6) | `Bph_adth = -dth2(Bph*uth,dth)/RR` | ○ |
| r sinθ B_r ∂Ω₁/∂r (6) | `Bph_omrr = Brr*omrr*RR*sinTH` | ○ |
| sinθ B_θ ∂Ω₁/∂θ (6) | `Bph_omth = Bth*omth*RR*sinTH` (omth に 1/r 込み) | ○ |
| η_t[Δ − 1/(r sinθ)²]B_Φ (6) | `Bph_dfrr + Bph_dfth + Bph_dfex` | ○ |
| (1/r)(∂η_t/∂r)∂_r(r B_Φ) (6) | `Bph_dfrrg = etrr*drr2(RR*Bph,drr)/RR` | ○ |
| −(v_r/r)∂_r(rA) (7) | `Aph_adrr = -drr2(Aph*RR,drr)*urr/RR` | ○ |
| −(v_θ/(r sinθ))∂_θ(sinθ A) (7) | `Aph_adth = -dth2(Aph*sinTH,dth)*uth/sinTH/RR` | ○ |
| η_t[Δ − 1/(r sinθ)²]A (7) | `Aph_dfrr + Aph_dfth + Aph_dfex` | ○ |
| B_r, B_θ の定義 (8)(9) | `poloidal_mag` | ○ |

**差分は2点だけ:**
- Rempel の α ソース (16)–(19) は 0.71–0.76 R⊙ を放物線カーネルで**非局所平均**する。
  S2MFD は `Bph[ibase,:]`(タコクライン1点)を使う。→ カーネル積分に置き換えるだけ。
- η_t の θ 微分項。η=η(r) なら 0 なので当面不要。

つまり **ダイナモ部分はほぼ完成している**状態です。

## 2. 何を足す必要があるか

Rempel 2006 は7つの予報変数を解きます:

| 変数 | 現状 | 備考 |
|---|---|---|
| B_Φ, A | **実装済み** | 上記のとおり式が一致 |
| ρ₁ | 新規 | 音速抑制法つき連続の式 |
| v_r, v_θ | **与えている** → 解く | 圧縮性・原始変数(流線関数でも渦度でもない) |
| Ω₁ | **与えている** → 解く | 角運動量方程式 |
| s₁ | 新規 | Rempel 2006 は解く(齊藤コードは固定) |

加えて必要なもの:

- **背景成層** ρ₀(r), p₀(r), T₀(r), g(r): 断熱ポリトロープの解析形(R05 21–24)。齊藤コードにそのままある。
- **Λ効果とレイノルズ応力** R_ik (R05 12–18, 31–33)。齊藤コードにそのままある。
- **ローレンツ力** F^B = ∇·(BB)/μ₀ + 磁気圧を p_tot に。**これが Rempel 2006 の本体**(2005 との差)。
- **音速抑制法** (RSST, ζ=1/100)。齊藤コードにある。
- **エネルギー収支診断** (R06 20–34)。Rempel が保存性の検証に使っている枠組み。

## 3. 保存則の設計(ご要望への対応)

### 3.1 角運動量: machine precision で保存

齊藤コードの手法をそのまま採用します。**要点は「保存量にヤコビアンを吸収させる」**こと:

    q_L = ρ₀ r⁴ sin³θ Ω₁   ( = ρ₀ r²sin²θ Ω₁ × r²sinθ )

こう置くと φ 方向の運動方程式が**源項ゼロの純粋な発散形**になります
(幾何項が全部相殺する)。齊藤コード `calculation.f90:91` は文字どおり源項なしです:

    ∂q_L/∂t = −∂_r[ρ₀r⁴sin³θ(Ω₀+Ω₁)v_r] − ∂_θ[ρ₀r³sin³θ(Ω₀+Ω₁)v_θ] + (応力の発散)

**粘性・Λ効果・マクスウェル応力も同じ発散形**に書けます:

| 輸送 | r フラックス | θ フラックス |
|---|---|---|
| 粘性 | ν_tρ₀ r⁴sin³θ ∂_rΩ₁ | ν_tρ₀ r²sin³θ ∂_θΩ₁ |
| Λ効果 | ν_tρ₀ r³sin²θ Λ_rφ | ν_tρ₀ r²sin²θ Λ_θφ |
| **マクスウェル** | **r³sin²θ B_r B_Φ/μ₀** | **r²sin²θ B_θ B_Φ/μ₀** |

マクスウェル応力が粘性・Λ と**同じ形**なので、フラックス配列を1本用意して
足し込むだけで済みます。これで**ローレンツ力も角運動量を再分配するだけ**になり、
machine precision の保存が保たれます。

**実装上の必須条件**(齊藤コードから):
1. 面フラックスを**配列に格納**し、`F[i] = (F_{i+1}+F_i)/2` として**一度だけ計算**
2. セル更新は `(F[i] − F[i−1])/Δr` — 隣接セルで**同じ浮動小数点値**を使う → ビット単位で telescoping
3. 境界の面フラックスを**リテラル 0.0 で上書き**(`bc0_x`/`bc0_y` 相当)。
   sinθ→0 に頼らない
4. SSP-RK2 は各段の増分がゼロ和なので、凸結合しても保存が保たれる

### 3.2 質量: machine precision で保存

RSST の連続の式 ∂ρ₁/∂t = −(1/ζ²)∇·(ρ₀v) に対し、保存量は **∫(ρ₀ + ζ²ρ₁)dV**
(ご指定のとおり)。同じ流儀で

    q_ρ = r²sinθ ρ₁,   フラックス = r²sinθ ρ₀v_r / ζ², r sinθ ρ₀v_θ / ζ²

とすれば telescoping で保存します。

### 3.3 境界から保存量を漏らさない (実装規律)

保存量が境界から出ていかないよう、**すべてのフラックスを例外なく**境界でゼロ化します。
「物理的にゼロになるはず」に頼らず、**リテラル 0.0 を代入**します
(sinθ→0 や v=0 の境界条件に頼ると、丸め誤差でわずかに漏れる)。

対象となるフラックスの**全リスト**(1本でも漏らすと保存が壊れる):

| 種別 | 角運動量 | 質量 |
|---|---|---|
| 移流 | ρ₀r⁴sin³θ(Ω₀+Ω₁)v_r, ρ₀r³sin³θ(Ω₀+Ω₁)v_θ | ρ₀r²sinθ v_r/ζ², ρ₀r sinθ v_θ/ζ² |
| 粘性 | ν_tρ₀r⁴sin³θ∂_rΩ₁, ν_tρ₀r²sin³θ∂_θΩ₁ | — |
| Λ効果 | ν_tρ₀r³sin²θΛ_rφ, ν_tρ₀r²sin²θΛ_θφ | — |
| **マクスウェル** | r³sin²θB_rB_Φ/μ₀, r²sin²θB_θB_Φ/μ₀ | — |
| **人工粘性** | 同じ保存量に対する拡散フラックス | 同左 |

**特に注意すべき点:**
- **人工粘性も物理と同じ扱い**にする。齊藤コードの `artdif` が無効化されているのは、
  まさにこれを別枠で処理して保存を壊していたため。
  → 人工拡散フラックスも同じ面配列・同じ境界ゼロ化・同じ差分演算子を通す。
- **マクスウェル応力**も忘れずにゼロ化する。上部境界は「ポロイダル場が動径方向」
  (B_θ=0) なので θ フラックスは物理的に消えるが、**明示的にゼロを入れる**。
- 上部の応力なし境界では Λ フラックスが tanh((r_max−r)/d) で消えるが、
  これも**数値的にゼロを代入**する。
- 極 (θ=0) と赤道 (θ=π/2) の面でも同様。極は sinθ→0 だが、
  セル中心格子では sin(Δθ/2)≠0 なので**明示ゼロ化が必須**。

**検証**: 全フラックスをゼロ化した閉じた系で、
∫q_L と ∫(ρ₀+ζ²ρ₁) の相対変化が数千ステップ後も **1e-14 以下**であることをテストで固定する。
境界フラックスを意図的に有効にした場合は、
「総量の変化 = 境界フラックスの時間積分」が machine precision で一致することも確認する。

### 3.4 散逸したエネルギーはエントロピーに戻す (必須)

**エントロピー方程式を解く以上、散逸したエネルギーの行き先を必ず用意します。**
処方は **Hotta (2017) ApJ 845:164 の式 (18)(19)** をそのまま使います。

#### 人工拡散 (slope-limited diffusion, Rempel 2014 系) の定義

方向ごと・変数ごとに、セル境界のフラックスを作ります (Hotta 2017 式 12–17):

    Δu_i = minmod[ (u_{i+1}−u_{i−1})/2, 2(u_{i+1}−u_i), 2(u_i−u_{i−1}) ]      (15)
    u_l  = u_i + 0.5 Δu_i,      u_r = u_{i+1} − 0.5 Δu_{i+1}                  (13,14)
    Φ    = max[ 0, 1 + h( (u_r−u_l)/(u_{i+1}−u_i) − 1 ) ]   ((u_r−u_l)(u_{i+1}−u_i) > 0)   (16)
    Φ    = 0                                                (それ以外)                     (17)
    f_{i+1/2} = −(1/2) c_{i+1/2} Φ (u_r − u_l)                                (12)

- `c_{i+1/2}` は境界での局所特性速度 (|v| + c_s、あるいは fast-mode 速度)。
  **論文中で定義されていない**ので自分で与える必要がある。
  音速抑制法を使うので c_s は抑制後の値を使う。
- `h` はハイパー拡散パラメタ。h=0 で局所 Lax-Friedrichs (最も散逸的)、
  大きいほど散逸が急峻な構造だけに集中する。
  Hotta 2017 の値: ρ に h=1、e_in に h=2、v と B に h=2 (小 Pm 実験では h_v=500)。
- **式 (12) は原論文で次元が合っていない** (Δx が余分)。上記の形が正しい
  (実効粘性 ν_art = (1/2) c Δx Φ に対応)。図4の単位から確認済み。

#### 散逸量の計算 (これが本題)

セル i での散逸率を、**更新に使ったのと同じフラックス**から解析的に求めます:

    ε_ν = −(1/2) Σ_m [ ρ_{i−1/2} f^m_{i−1/2}(v^m) (v^m_i − v^m_{i−1})/Δx
                      + ρ_{i+1/2} f^m_{i+1/2}(v^m) (v^m_{i+1} − v^m_i)/Δx ]     (18)

    ε_η = −(1/(2μ₀)) Σ_m [ f^m_{i−1/2}(B^m) (B^m_i − B^m_{i−1})/Δx
                          + f^m_{i+1/2}(B^m) (B^m_{i+1} − B^m_i)/Δx ]           (19)

(原論文は Gauss 単位で 1/8π。SI では 1/(2μ₀)。)

これは「フラックス × 勾配」の形で、フラックス形拡散 ∂_t u = −∂_x f に対する
エネルギー損失率の厳密な表式です
(∂_t(½ρu²) = −∂_x(ρuf) + ρf∂_x u の第2項が局所シンク)。
**「適用前後のエネルギー差を測る」のではなく、フラックスから直接計算します。**

#### エントロピー方程式への追加

Hotta 2017 は**全エネルギー方程式**を解くので、ε_ν, ε_η は自動的に内部エネルギーに
移り、方程式には足しません(論文明記)。**我々はエントロピーを解くので明示的に足します**:

    ρ T ∂s/∂t += ε_ν + ε_η          (係数はちょうど 1)

あるいは無次元エントロピー s₁ を使う Rempel の書き方なら

    ∂s₁/∂t += ((γ−1)/p₀) (ε_ν + ε_η)

Rempel 2006 式 (5) が既に持つ物理粘性の Q (R05 19) とオーム散逸 η_t(∇×B)² に
**並べて足す**形になります。

#### 正値性は構造的に保証される

Φ ≥ 0 (式16の max[0,·]) かつ (u_r−u_l)(u_{i+1}−u_i) ≤ 0 のとき Φ=0 (式17) なので、
各境界で

    −f_{i+1/2}(u_{i+1}−u_i) = (1/2) c Φ (u_r−u_l)(u_{i+1}−u_i) ≥ 0

**式 (17) の符号ガードが決定的**です。これを落とすと局所的に反拡散が起きて
「負の散逸 = 非物理的な冷却」になります。ε_ν, ε_η ≥ 0 をテストで assert します。

#### 実装上の注意

- **同じ substep で、同じフラックスを使う**。別々に計算すると収支が閉じない。
- **局所的に(セルごとに)加熱する**。Hotta 2017 の結論は「散逸の空間的偏りは
  エントロピー構造に一次で効く」(対流反転時間の2倍で効く)というものなので、
  領域平均でならしてはいけない。
- **内部エネルギーへの人工拡散は熱伝導であって摩擦加熱ではない**。二重計上しない。
- 角運動量成分 (Ω₁) の人工拡散による散逸も忘れずに含める。
- **保存形との両立**: Hotta 2017 は Cartesian で **原始変数 v に**拡散をかけており
  (式18 に ρ_{i±1/2} の重みが付くのはそのため)、∫ρv は厳密には保存しません。
  **我々は角運動量保存が要求なので、保存量 ρ₀r⁴sin³θΩ₁ に対して拡散をかけます**
  (この点は論文からの意図的な変更)。その場合 ε は上式を保存量ベースで
  書き直す必要があります。
- 検証: ∫(ε_ν + ε_η)dV を全エネルギー収支に組み込み、残差が
  Rempel の報告値 (Q_Λ の 0.001) 以下に収まることを確認する
  (Hotta 2017 式26 の閉じ具合テストに相当)。

#### 副産物: 実効的な拡散係数がわかる

Hotta 2017 は擬似散逸 D_ν (式20), D_η (式21) を定義して

    ν_eff = ε_ν / D_ν,     η_eff = ε_η / D_η

で**人工拡散が実効的にどれだけの粘性・磁気拡散を課しているか**を測っています。
平均場ダイナモでは η_t が本質パラメタなので、
**人工拡散が η_t を汚染していないかを定量的に確認できる**のは重要です。
診断として実装します。

### 3.5 全エネルギー: 保存しないので監視する

Rempel 2006 は式 (20)–(34) で**完全なエネルギー収支の枠組み**を与えています:

    ∂E_Ω/∂t = Q_Λ − Q_ν^Ω − Q_C − Q_L^Ω
    ∂E_M/∂t = Q_C − Q_ν^M − Q_B − Q_L^M
    ∂E_B/∂t = Q_L^Ω + Q_L^M − Q_η

E_Ω(差動回転)、E_M(子午面流)、E_B(磁気)の3つの貯蔵庫と、
Λ効果による注入 Q_Λ、粘性散逸 Q_ν、コリオリ変換 Q_C、浮力 Q_B、
ローレンツ変換 Q_L、オーム散逸 Q_η。

**論文は収支の閉じ具合が Q_Λ の 0.001 以内と報告**しています(Table 1 注)。
これをそのまま診断として実装すれば、「全エネルギーがどう変化しているか」を
項別に追跡でき、しかも**論文の数値と直接比較して検証**できます。

## 4. 数値スキームの注意点

**Rempel は MacCormack 法**(予測子修正子、上流・下流差分を交互に使う)を使っています。
S2MFD / 齊藤コードの **SSP-RK2 + 中心差分**は次数は同じですが、
MacCormack が持つ**暗黙の上流散逸がありません**。

齊藤コードはここで苦労した形跡があります: 人工拡散 `artdif.f90` を書いたものの、
**保存量が本体と違う**(ρ₀ を含まない `r²sinθ v_φ`)ため角運動量保存を壊し、
結局**無効化されています**(`mhd.f90:44` でコメントアウト)。

**解決策は明確**で、人工拡散も本体と同じ枠組みに載せます:
- 保存量 `ρ₀r⁴sin³θΩ₁` に対する拡散フラックスとして定義
- 面配列に格納し、境界で 0 にし、本体と同じ差分演算子を通す

こうすれば人工拡散も**再分配のみ**になり、保存と安定性が両立します。
齊藤くんが粘性項とΛ効果に対して既にやっているのと同じ手口です。

なお現行 S2MFD の移流も純中心差分で、レビューで指摘した「Pe>2 で格子振動」の
問題を抱えています。流れ場を解くと音波も入るので、この対策は事実上必須になります。

## 5. 実装計画(段階と検証)

各段階で**論文の数値と突き合わせられる**ように区切ってあります。

### Phase A: 背景成層 + 保存形の骨格 (検証: 保存則)
- ρ₀,p₀,T₀,g の解析形、格子(既存の Grid を 0.65–0.985 R⊙ に)
- 保存形の差分演算子(面フラックス配列 + 境界ゼロ化)
- **検証**: 移流のみのテスト問題で ∫q_L, ∫q_ρ の相対変化が **1e-14 以下**

### Phase B: 流体部分 (検証: Rempel 2006 Fig. 1)
- ρ₁, v_r, v_θ, Ω₁ + Λ効果 + レイノルズ応力 + RSST
- エントロピーは当面 Rempel の δ(r) を使う(または齊藤流に固定)
- **検証**:
  - (Ω_eq−Ω_pole)/Ω₀ = **0.27**
  - 表面 v_θ ≈ −10 m/s、戻り流 ≈ +2.5 m/s @ 0.75 R⊙
  - Q_Λ = 0.014 F⊙、Q_ν^Ω/Q_Λ = 0.574、Q_C/Q_Λ = 0.425

### Phase C: 運動学ダイナモ (検証: Fig. 3)
- Phase B の Ω, v を**固定**して既存の誘導ソルバを回す
- α ソースを Rempel の非局所カーネルに
- **検証**: 周期 **19年**、B_Φ,max = **1.28 T** @ 0.735 R⊙、B_r,max = 0.01 T

### Phase D: ローレンツ力の結合 (検証: Fig. 4 = 本命)

## 5.5 kinematic dynamo モードの維持 (必須要件)

**現行の運動学的ダイナモ機能はそのまま残します。** 具体的には:

- `S2MFD.inference`(GAパラメタ推定)は**一切変更しない**。
  論文 Shimizu & Hotta (2026) の再現性を壊さないことが最優先。
- `cfg` に**モード切替**を持たせる:

  | モード | 解く方程式 | 用途 |
  |---|---|---|
  | `kinematic` (既定) | 誘導のみ、流れは `uu0_of_time` 等で与える | 現行の GA 推定・既存の全解析 |
  | `dynamic` | 誘導 + 流体 + ローレンツ力 | Rempel 2006 |
  | `hydro` | 流体のみ(磁場なし) | Rempel 2005 / 齊藤修論の再現、Phase B の検証 |

- 実装は**加算的**にする。既存の `time_marching` / `run_window` / `spin_up` は
  そのまま残し、`dynamic` モードでは追加の予報変数を持つ別経路を通す。
- **既存の110テストとゴールデンデータが通り続けること**を各段階で確認する。
  特に `tests/test_kernel_equivalence.py` の「参照実装とビット一致」は維持する。
- ドキュメントにも3モードの使い分けを明記する。

これにより、学生が GA 推定を回している間に Rempel の開発を進めても干渉しません。

## 6. 規模と計算コストの見積もり

**コード規模**: 齊藤コードの流体部分が Fortran 1505行。Python/numba で書くなら
同程度〜やや少なめ + ローレンツ力・エントロピー・診断で **2000〜2500行**程度。

**計算コスト**: Rempel の設定(108×72、ζ=0.01)で
- Δt ≈ 10³ s(抑制音速の CFL 律速)
- 20年 ≈ 6×10⁵ ステップ

現行 S2MFD の最適化後カーネル(128×128 で 0.044 ms/substep)を流用できれば、
1変数あたり同程度として7変数で ~0.3 ms/substep → **20年で約10分**。
十分に実用的です(最適化前なら2時間半)。今回の高速化がそのまま効きます。

## 7. リスクと未確定事項

1. **論文に書かれていない詳細**: α カーネル h(r) の正確な形(「0.71と0.76で0、

   Fig. 1 の再現で確認できます。
4. **タコクライン**: Rempel は 0.65 R⊙ で Ω₁=0 を課して**強制的に**作っています。
