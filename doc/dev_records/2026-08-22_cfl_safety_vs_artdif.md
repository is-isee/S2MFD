# CFL 安全率 0.5 は人工拡散を弱めると足りない (2026-08-22)

## 事実

論文設定 (北半球・0.985 RSUN・108x72・margin=2) で `sld_cs_factor` を
振ったところ、**0.20 だけが発散した**。より弱い 0.15 は安定。

| sld_cs_factor | dt [s] | 結果 |
|---|---|---|
| 0.15 | 283.5 | 安定 |
| **0.20** | **283.5** | **発散** (t=1.13yr で v_r=117 m/s、t=1.55yr で DR=-1.66) |
| 0.30 (既定) | 216.1 | 安定 |
| 0.40 | 162.1 | 安定 |
| 0.50 | 129.7 | 安定 |

0.15 と 0.20 は **dt が同じ 283.5 s**。この範囲では SLD の拡散 CFL が
律速でなくなり、`cfl_dt` が別の制約 (音速抑制後の音波) で dt を決めている。

## 切り分け

`cfl_safety` を 0.5 -> 0.25 にして cs_factor=0.20 を再投入すると
(dt = 141.7 s)、元のランが既に v_r = 117 m/s になっていた t = 1.20 yr の
時点で v_r = 0.75 m/s と正常だった。

→ **発散は物理ではなく時間積分の安定性**。

## 意味

`cfl_safety` は 2026-08-21 のコミット 4cbeb17 で 0.2 -> 0.5 に上げた
(2.5 倍の高速化)。von Neumann 解析 (2026-08-21_cfl_von_neumann.md) は
既定の人工拡散を前提にしている。**人工拡散を弱めると SLD が担っていた
安定化が減り、0.5 では余裕がなくなる。**

人工拡散は論文にない項なので、その極限 (cs_factor -> 0) で差動回転が
論文の 0.27 に収束するかは収束性の主張に直接関わる。その極限を取る
ときは `cfl_safety` も一緒に下げる必要がある。

## 対応

- スキャンの cs_factor <= 0.2 は `cfl_safety=0.25` で走らせる。
- 既定の 0.5 は cs_factor=0.3 以上でのみ検証済み、と理解しておく。
