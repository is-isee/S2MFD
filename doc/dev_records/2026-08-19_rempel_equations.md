   The Role of a Subadiabatic Tachocline for the Taylor-Proudman Balance"
- **Rempel 2006** = ApJ 647, 662
  "Flux-Transport Dynamos with Lorentz Force Feedback on Differential Rotation
   and Meridional Flow: Saturation Mechanism and Torsional Oscillations"

## 1. 基礎方程式 (Rempel 2006 式 1-9)

`s = r sinθ` (円筒半径)、`Ω = Ω₀ + Ω₁`、`p_tot = p₁ + p_mag`。

### 連続の式 (1)

```
∂ϱ₁/∂t = − (1/r²) ∂/∂r ( r² v_r ϱ₀ ) − (1/(r sinθ)) ∂/∂θ ( sinθ v_θ ϱ₀ )
```

### 動径運動量 (2)

```
∂v_r/∂t = − v_r ∂v_r/∂r − (v_θ/r) ∂v_r/∂θ + v_θ²/r
          − ∂/∂r ( p_tot/ϱ₀ ) + ( p_mag/(γ p₀) ) g + ( s₁/γ ) g
          + ( 2Ω₀Ω₁ + Ω₁² ) r sin²θ + (1/ϱ₀)( F_r^ν + F_r^B )
```

浮力項の書き方は 2005 式 (2) の `−(1/ϱ₀)[ϱ₁ g + ∂p₁/∂r]` と代数的に等価
(|∇−∇_ad| ≪ 1 を仮定)。磁気浮力を分離するためにこの形にしている。
軸対称モデルでの磁気浮力は現実的でないので、`p_mag` 項を落とした計算も
論文中で比較されている。

### 子午面運動量 (3)

```
∂v_θ/∂t = − v_r ∂v_θ/∂r − (v_θ/r) ∂v_θ/∂θ − v_r v_θ/r
          − (1/r) ∂/∂θ ( p_tot/ϱ₀ )
          + ( 2Ω₀Ω₁ + Ω₁² ) r sinθ cosθ + (1/ϱ₀)( F_θ^ν + F_θ^B )
```

### 角運動量 (4)

**移流形**で、Ω₁ の方程式として書かれている (保存形ではない)。

```
∂Ω₁/∂t = − (v_r/r²) ∂/∂r [ r² (Ω₀+Ω₁) ]
         − (v_θ/(r sin²θ)) ∂/∂θ [ sin²θ (Ω₀+Ω₁) ]
         + ( F_φ^ν + F_φ^B ) / ( ϱ₀ r sinθ )
```

> **移流には Ω₀+Ω₁ の全体が入るが、粘性・Λ 応力は Ω₁ にしか効かない**
> (式 17-18 参照)。剛体回転部分はせん断を生まないため。この非対称性は
> 再実装時に間違えやすい。

### エントロピー (5)

```
∂s₁/∂t = − v_r ∂s₁/∂r − (v_θ/r) ∂s₁/∂θ
         + v_r γδ/H_p
         + ((γ−1)/p₀) Q
         + (1/(ϱ₀T₀)) ∇·( κ_t ϱ₀ T₀ ∇s₁ )
         + ((γ−1)/p₀) η_t (∇×B)²                      ← 2006 で追加
```

左辺は素の `∂s₁/∂t` (`ϱ₀T₀ ∂s₁/∂t` ではない)。最後のオーム散逸項だけが
2005 からの変更点。

### 誘導方程式 (6), (7)

```
∂B_Φ/∂t = − (1/r) ∂/∂r ( r v_r B_Φ ) − (1/r) ∂/∂θ ( v_θ B_Φ )
          + r sinθ B_r ∂Ω₁/∂r + sinθ B_θ ∂Ω₁/∂θ
          + η_t [ Δ − 1/(r sinθ)² ] B_Φ
          + (1/r)(∂η_t/∂r) ∂/∂r ( r B_Φ )
          + (1/r²)(∂η_t/∂θ)(1/sinθ) ∂/∂θ ( sinθ B_Φ )

∂A/∂t = − (v_r/r) ∂/∂r ( r A ) − (v_θ/(r sinθ)) ∂/∂θ ( sinθ A )
        + η_t [ Δ − 1/(r sinθ)² ] A + S(r,θ,B_Φ)

B_r = (1/(r sinθ)) ∂/∂θ ( sinθ A ),   B_θ = − (1/r) ∂/∂r ( r A )
```

Ω 効果に入るのは **Ω₁ のみ** (Ω₀ ではない)。

### 状態方程式 (2005 式 6, 7)

```
p₁ = p₀ ( γ ϱ₁/ϱ₀ + s₁ ),     H_p = p₀/(ϱ₀ g)
```

> **s は c_v で無次元化されている** (`s = ln(p ϱ^{−γ})` を c_v = (γ−1)⁻¹R/μ で割った量)。
> c_p ではない。物理エントロピーとの関係は `s_phys = c_v s₁`。
> 齋藤コードの `en1` はこの `s₁` と同一。

## 2. レイノルズ応力と粘性 (Rempel 2005 式 9-18)

### 粘性力 (9)-(11)

```
F_r = (1/r²) ∂/∂r ( r² R_rr ) + (1/(r sinθ)) ∂/∂θ ( sinθ R_θr ) − ( R_θθ + R_φφ )/r
F_θ = (1/r²) ∂/∂r ( r² R_rθ ) + (1/(r sinθ)) ∂/∂θ ( sinθ R_θθ ) + ( R_rθ − R_φφ cotθ )/r
F_φ = (1/r²) ∂/∂r ( r² R_rφ ) + (1/(r sinθ)) ∂/∂θ ( sinθ R_θφ ) + ( R_rφ + R_θφ cotθ )/r
```

### 応力テンソル (12)

```
R_ik = − ϱ₀ ⟨v_i' v_k'⟩ = ν_t ϱ₀ ( E_ik − (2/3) δ_ik ∇·v + Λ_ik )
```

**Λ 効果にも ν_t ϱ₀ が掛かる**ことに注意 (齋藤コードも同じ)。

### 変形テンソル (13)-(18)

```
E_rr = 2 ∂v_r/∂r
E_θθ = 2 (1/r) ∂v_θ/∂θ + 2 v_r/r
E_φφ = (2/r) ( v_r + v_θ cotθ )
E_rθ = r ∂/∂r ( v_θ/r ) + (1/r) ∂v_r/∂θ
E_rφ = r sinθ ∂Ω₁/∂r          ← Ω₁ のみ
E_θφ = sinθ ∂Ω₁/∂θ            ← Ω₁ のみ
```

### Λ 効果 (2005 式 31-33)

```
Λ_rφ = + L(r,θ) cos( θ + λ(r,θ) )
Λ_θφ = − L(r,θ) sin( θ + λ(r,θ) )

f(r,θ) = sin^n θ cosθ tanh( (r_max − r)/d )
L(r,θ) = Λ₀ Ω₀ f(r,θ) / max| f(r,θ) |
```

- `λ` は角運動量フラックスベクトルの回転軸からの傾き (Λ₀ とは別物)。
  `λ=0` は回転軸に平行で下向き、`λ=−θ` は動径内向き、`λ=π/2−θ` は赤道向き。
- **対称性**: Λ_rφ は赤道について対称、Λ_θφ は反対称でなければならない。
  そのためには λ と L がともに赤道について**反対称**である必要がある。
  Rempel は北半球のみを解くので、以下の値はすべて北半球のもの。
  → **全球格子で解く場合は λ の符号を半球ごとに反転させる必要がある**
    (S2MFD 実装済み: `Setup.build_lambda`)。
- **λ > 0 のときは n > 2 が必要** (極近傍でレイノルズ応力の発散が正則になるため)。
  Rempel 2006 は **n = 3**。齋藤コードの n = 2 は λ=15° と組み合わせると
  この条件を満たさない。
- `d = 0.025 R⊙` (上端でフラックスをゼロにする遷移層)。

## 3. 背景成層 (Rempel 2005 式 21-24)

断熱ポリトロープ、重力 `g ∝ r⁻²`。

```
T₀(r) = T_bc [ 1 + ((γ−1)/γ)(r_bc/H_bc)( r_bc/r − 1 ) ]
p₀(r) = p_bc [ … ]^{γ/(γ−1)}
ϱ₀(r) = ϱ_bc [ … ]^{1/(γ−1)}
g(r)  = g_bc ( r/r_bc )^{−2}
```

| 記号 | 値 (SI) | 値 (CGS) |
|---|---|---|
| r_bc | 0.71 R⊙ | 同 |
| p_bc | 6×10¹² Pa | 6×10¹³ dyn/cm² |
| ϱ_bc | 200 kg/m³ | 0.2 g/cm³ |
| g_bc | 520 m/s² | 5.2×10⁴ cm/s² |
| H_bc | 0.0825 R⊙ | 同 |
| R⊙ | 7×10⁸ m | 7×10¹⁰ cm |

T_bc は論文に明示されていない。齋藤コードは `1.82×10⁶ K` を使う
(`p_bc/(ϱ_bc T_bc) = R/μ` が妥当な値になる)。

**ポリトロープの外端**: この係数だと密度がゼロになる半径は約 `1.0007 R⊙`。
Rempel は上端を `0.985 R⊙`、齋藤は `0.96 R⊙` に取っている。

## 4. 超断熱度 δ(r) (Rempel 2005 式 25-26)

```
δ       = δ_conv + (1/2)( δ_os − δ_conv )[ 1 − tanh( (r − r_tran)/d_tran ) ]
δ_conv  = δ_top exp( (r − r_max)/d_top ) + δ_cz ( r − r_sub )/( r_max − r_sub )
```

`δ = ∇ − ∇_ad`。**δ > 0 が超断熱 (対流不安定)、δ < 0 が亜断熱**。
背景エントロピー勾配との関係は

```
ds₀/dr = − γ δ / H_p                                    (2005 式 8)
```

なのでエントロピー方程式の第3項は `+ v_r γδ/H_p`。

**Rempel 2006 の参照モデル = Rempel 2005 の case 1**:

| 記号 | 値 |
|---|---|
| δ_os | −1.5×10⁻⁵ |
| r_tran | 0.725 R⊙ |
| d_tran | 0.0125 R⊙ |
| d_top | 0.0125 R⊙ |
| δ_conv | 0 (断熱対流層) |
| d_κν | 0.025 |
| α_κν | 0.1 |

放射層 (r < 0.71 R⊙) の実際の太陽値は δ ~ −0.1 だが、**音速抑制法では
δ が ζ² 倍されるので ζ=100 だと δ=−1000 相当になり物理的に不可能**。
オーバーシュート程度の δ ~ −10⁻⁵ なら問題ない (2005 §2.6 に明記)。

## 5. 拡散係数

### 乱流粘性・熱伝導 (2005 式 27-30)

```
ν_t = (ν₀/2)[ 1 + tanh( (r − r_tran + Δ)/d_κν ) ] f_c(r)
κ_t = (κ₀/2)[ 1 + tanh( (r − r_tran + Δ)/d_κν ) ] f_c(r)
f_c(r) = (1/2)[ 1 + tanh( (r − r_bc)/d_bc ) ]          d_bc = 0.0125 R⊙
Δ = d_κν tanh⁻¹( 2 α_κν − 1 )
```

**重要な非対称性**: 上の式 (27) は **Λ 効果による角運動量輸送**に使う。
一方、レイノルズ応力の**拡散項に使う粘性は対流層値の 2%** に、
**熱伝導は 0.2%** に設定する (放射層でゼロに落とさない)。
これは Ω₁=0 の下部境界条件との間にせん断層 (タコクライン) を
現実的な時間で形成させるため。

| モデル | ν₀ = κ₀ |
|---|---|
| Rempel 2005 | 5×10⁸ m²/s = 5×10¹² cm²/s |
| **Rempel 2006 参照モデル** | **3×10⁸ m²/s = 3×10¹² cm²/s** |

### 磁気拡散 (2006 式 13-15)

```
η_t = η_c + f_c(r)[ η_bc − η_c + f_cz(r)( η_cz − η_bc ) ]
f_cz(r) = (1/2)[ 1 + tanh( (r − r_cz)/d_cz ) ]
f_c(r)  = (1/2)[ 1 + tanh( (r − r_bc)/d_bc ) ]
```

| 記号 | 値 (SI) | 値 (CGS) |
|---|---|---|
| η_c | 10⁵ m²/s | 10⁹ cm²/s |
| η_bc | 10⁶ m²/s | 10¹⁰ cm²/s |
| η_cz | 10⁸ m²/s | 10¹² cm²/s |
| r_cz | 0.875 R⊙ | 同 |
| d_cz | 0.05 R⊙ | 同 |
| r_bc | 0.71 R⊙ | 同 |
| d_bc | 0.0125 R⊙ | 同 |

### クエンチング (2006 式 10-11、§4.3 のみ)

```
ν_t = ν_t⁰ / ( 1 + (B/B_eq)² ),   κ_t = κ_t⁰ / ( 1 + (B/B_eq)² ),   B_eq = 1 T
```

## 6. Babcock-Leighton α 効果 (2006 式 16-19)

```
S(r,θ,B_Φ) = α₀ B̄_{Φ,bc}(θ) f_α(r) g_α(θ)
f_α(r) = max[ 0, 1 − (r − r_max)²/d_α² ]           d_α = 0.05 R⊙
g_α(θ) = sin²θ cosθ / max[ sin²θ cosθ ]
B̄_{Φ,bc}(θ) = ∫ dr h(r) B_Φ(r,θ)
```

`h(r)` は 0.71 と 0.76 R⊙ でゼロになり 0.735 R⊙ でピークを持つ放物線カーネル、
`∫dr h(r) = 1` に規格化。α₀ = 0.125 / 0.25 / 0.5 m/s (表面冷却の計算では 0.1)。

## 7. 境界条件

### Rempel 2005 (§2.6)

領域は緯度が赤道-極、動径が **0.65 - 0.985 R⊙**。解像度は動径 108 × 緯度 72。

| 変数 | r = 0.65 R⊙ | r = 0.985 R⊙ | 赤道・極 |
|---|---|---|---|
| v_r | 閉 (v_r = 0) | 閉 (v_r = 0) | 対称性 |
| v_θ | stress-free | stress-free | 対称性 |
| **Ω₁** | **Ω₁ = 0 (Dirichlet)** | stress-free (R_rφ = 0) | 対称性 |
| s₁ | ∂s₁/∂r = 0 | ∂s₁/∂r = 0 | 対称性 |

> **系は角運動量について閉じていない。**
> 下部境界は固定 Ω のリザーバであり、粘性フラックス R_rφ ≠ 0 がそこを通る。
> Rempel はこれを「物理的なタコクラインではなく人為的な装置」と明言している:
>
> *"In this model we do not include a sophisticated theory for the tachocline but
> force a tachocline through a uniform rotation boundary at r = 0.65 R⊙.
> As a consequence the tachocline is a viscous shear layer between the convection
> zone and the lower boundary condition."*

**S2MFD 実装上の含意**: ユーザー要求「角運動量を machine precision で保存」と
Rempel の下部境界条件は**そのままでは両立しない**。両方を提供する:

- `angmom_bottom_bc = 'stress_free'` — 閉じた系。∫q_L が machine precision で保存
  (齋藤 2024 と同じ)。
- `angmom_bottom_bc = 'uniform_rotation'` — Rempel 2006 の再現用。境界フラックスを
  明示的に積算し、`∫q_L(t) − ∫q_L(0) = ∫dt (境界フラックス)` が machine precision で
  成立することを検証する (「漏れを許す」のではなく「漏れを厳密に勘定する」)。

### Rempel 2006 の磁場境界条件 (§2.2)

```
極:   A = B_Φ = 0
赤道: ∂A/∂θ = B_Φ = 0        (双極子対称性を選択)
両動径境界: B_Φ = 0
内側境界:   A = 0
上部境界:   ポロイダル場は動径方向 (radial field)
```

流体側は 2005 のものを継承 (「B_Φ 以外はすべて閉じた境界条件」)。

## 8. 数値解法

### スキーム

> *"We solve equations (1)-(5) with a **MacCormack scheme using alternating
> upwind and downwind differencing, which is second order in space and time**."*
> (Rempel 2005 §2.6; 2006 も同じ)

**人工粘性・ハイパー拡散・フィルタは論文中に一切記述がない。**
散逸はすべて物理的な ν_t, κ_t, η_t と、MacCormack の交互風上/風下差分に内在する
数値散逸による。

> **S2MFD 実装上の含意**: S2MFD は SSP-RK2 + 中心差分で、数値散逸を持たない。
> したがって**人工拡散が別途必要**になる。これは論文からの逸脱ではなく、
> 異なる時間積分法を使うことの必然的な帰結。Hotta (2017) の
> slope-limited diffusion を保存形に書き直して使い、散逸した運動エネルギー・
> 磁場エネルギーはエントロピー方程式に戻す (ユーザー要求)。

### 音速抑制法 (2005 式 34-35 / 2006 式 12)

2005 の変換 (基準回転数を上げる形):

```
Ω₀ → ζΩ₀,  ν_t → ζν_t,  κ_t → ζκ_t,  δ → ζ²δ,  t → ζ⁻¹t
v_r → ζv_r, v_θ → ζv_θ, Ω₁ → ζΩ₁,  p₁ → ζ²p₁, ϱ₁ → ζ²ϱ₁, s₁ → ζ²s₁
```

これで式 (2)-(5) は不変のまま、連続の式だけが

```
∂ϱ₁/∂t + (1/ζ²) ∇·( ϱ₀ v ) = 0          (2005 式 35、ζ = 100)
∂ϱ₁/∂t = − ζ² ∇·( ϱ₀ v )                 (2006 式 12、ζ = 0.01)
```

> **⚠ 2 論文で ζ の規約が逆数**。2005 は ζ=100 で 1/ζ²、2006 は ζ=0.01 で ζ²。
> どちらも音速を 100 分の 1 にする。混ぜないこと。
> S2MFD は 2005 の規約 (`rsst_zeta = 100`) を採用。

ζ=10 と ζ=100 の差は数 % (主に極近傍の差動回転の大きさ) と報告されている。

## 9. エネルギー収支 (Rempel 2006 式 20-34)

`s = r sinθ`、`∫dV = 4π ∫dr ∫dθ r² sinθ`。

```
∂E_Ω/∂t = Q_Λ − Q_ν^Ω − Q_C − Q_L^Ω
∂E_M/∂t = Q_C − Q_ν^M − Q_B − Q_L^M
∂E_B/∂t = Q_L^Ω + Q_L^M − Q_η

E_Ω = ∫dV (1/2) ϱ₀ s² Ω²          (差動回転のエネルギー)
E_M = ∫dV ϱ₀ v_m²/2               (子午面循環のエネルギー)
E_B = ∫dV B_Φ²/(2μ₀)              (トロイダル磁場のエネルギー)

Q_Λ   = − ∫dV ν_t ϱ₀ s ( ∂Ω/∂r Λ_rφ + (1/r) ∂Ω/∂θ Λ_θφ )
Q_ν^Ω = ∫dV ν_t ϱ₀ s² [ (∂Ω/∂r)² + ((1/r)∂Ω/∂θ)² ]
Q_C   = − ∫dV s² ϱ₀ v_m · ∇( Ω²/2 )
Q_L^Ω = − ∫dV Ω B_p · ∇( s B_Φ )
Q_ν^M = ∫dV (1/2)( R_rr E_rr + 2 R_rθ E_rθ + R_θθ E_θθ + R_φφ E_φφ )
Q_B   = − ∫dV v_r ϱ₀ g s₁/γ
Q_L^M = ∫dV (B_Φ/s) v_m · ∇( s B_Φ )
Q_η   = ∫dV (η_t/s²) { [∂(sB_Φ)/∂r]² + [(1/r)∂(sB_Φ)/∂θ]² }
```

磁気浮力を含める場合は `Q_B = − ∫dV v_r ϱ₀ g (1/γ)( s₁ − p_mag/p₀ )` (式 37)。

平衡関係:

```
Q_Λ = Q_ν^Ω + Q_C + Q_L^Ω
Q_C = Q_ν^M + Q_B + Q_L^M
Q_η = Q_L^Ω + Q_L^M
```

論文は「エネルギー交換項の精度は 0.001 程度なので、これらの関係はその誤差の
範囲でしか満たされない」と注記している。**我々の実装ではこの残差を診断として
出力し、論文の 0.001 と比較できるようにする。**

## 11. 論文中の疑わしい記述 (実装時に注意)

原論文の印刷そのままだが、次元やスケールが合わない箇所。転記した調査では
「推測で直さず、そのまま報告する」方針を取った。

1. **2006 式 (5) の `η_t (∇×B)²` と式 (33) の `Q_η` に μ₀ がない。**
   η_t [m²/s]、(∇×B)² [T²/m²] なので単位は T²/s。体積加熱率にするには
   `1/μ₀` が要る。一方で式 (25) の `E_B = ∫dV B_Φ²/(2μ₀)` には μ₀ がある。
   → **実装では 1/μ₀ (CGS では 1/4π) を入れる。**
2. **2006 式 (38) の前の `F_c = κ_t ϱ₀ T₀ c_v ∇s₁` の符号が `+`。**
   勾配拡散フラックスなら `−` のはず。2005 式 (20) では `− κ_t ϱ₀T₀ ∇s₁` と
   正しく書かれている。→ **実装では `−` を採用。**
3. **2005 式 (10) の F_θ の最終項が `+(R_rθ − R_φφ cotθ)/r`。**
   標準的な球座標のテンソル発散と形が違う。齋藤コードの実装
   (`reyno` の t3) を正とする。
4. **δ_cz の符号。** 図 1 のキャプションと表 1 の注はどちらも
   `δ_cz = 3×10⁻⁶` と正の値で印字されているが、本文は δ_cz を
   「対流層バルクの超断熱度」と説明している。式 (26) では δ_cz は
   `(r − r_sub)/(r_max − r_sub)` に掛かる**傾き係数**であり、
   正の δ_cz なら r < r_sub で弱く亜断熱、r > r_sub で超断熱になる。
   式 (26) と整合するのは正の値。
5. **Rempel 2006 は δ(r) プロファイル、Λ 効果の式、粘性応力テンソル、
   格子解像度を一切再掲していない。** すべて Rempel 2005a の case 1 への
   参照で、変更点は n=3, Λ₀=1, ν_t=κ_t=3×10⁸ m²/s のみ (λ=15° は §5 で確認)。
