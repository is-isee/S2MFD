## 総評

物理定式化と離散化は Jouve et al. (2008) 準拠+圧縮項で概ね正しく、修論付録5.3のベンチマークでも検証されている。一方で、パッケージング・テスト・エラー処理などソフトウェアとしての基盤に改善余地が大きい。特に GA パラメタ推定層(IDPA)を統合する前提では、「派生パラメタの読込時固定」「実行ごとの出力分離」「異常検知」が障害になる。

凡例: 【重大】数値結果や実行可否に影響 /【設計】将来の拡張・保守の障害 /【品質】保守性・可読性 /【性能】速度・資源

## 1. 重大(数値結果・実行可否に影響)

### 1.1 出力タイムスタンプの1ステップずれ →【今回修正】
`simulation.py:148-183` の `main_loop` は「`time += dt` → 出力判定・save → `tvd_runge_kutta()`」の順のため、保存される場は time−dt 時点の状態なのに time のラベルが付く。dt≈1.6日、dtout=40日なので物理的影響は小さいが、観測との時刻合わせを行う GA では系統誤差になる。
**対処**: ループを「積分 → 時刻更新 → 出力」の順に修正。既存データとの比較では1ステップ分の差が出る(意図的な変更として記録)。

### 1.2 リスタート経路の0次元配列問題 →【今回修正】
`grid.py:136` / `S2MFD/setup.py:161` / `legendre.py:55` の `load()` は `np.savez` 経由でスカラー(`drr`, `margin`, `ixg`, `ibase`, `lmax` など)が0次元 ndarray になったまま復元し、`@njit` カーネル(`tools.py`)に渡すと Numba の型付けが崩れる。`data.py:109-110` の `time`/`n` も同様。
**対処**: load 時に `v.item() if v.ndim == 0 else v` で型を戻す。3クラスに全く同じ save/load が3重複しているので共通化。

### 1.3 cont_flag=True の暗黙再開と config 不整合 →【今回一部修正】
`defaults.py:60` で `cont_flag=True` がデフォルト。既存 datadir があると黙って再開する。**この「何も考えなければ続き」はプロジェクトの意図した仕様**(2026-08-19 ユーザー確認)なのでデフォルトは維持するが、現状は再開時に古い `grid.npz`/`setup.npz` を使いながら新しい `config.json` を上書きするため(`simulation.py:38-48`)、パラメタを変えて再実行すると「config.json が実際の setup と食い違う」不整合が黙って発生する。
**対処**: 再開を明示表示し、既存 config.json との整合性チェックを追加(不一致はエラー)。GA 層は個体評価で常に新規実行を強制。

### 1.4 パッケージング破損 →【今回修正】
`/setup.py:5` が `packages=['S2MFD']` のみでサブパッケージ(`physics`, `tools`, `parameters`)未宣言。非 editable の `pip install .` は import 不能なパッケージを作る(現在 `pip install -e .` 前提で隠れている)。`pyproject.toml` に `[project]` テーブルがなく、`requirements.txt`(完全ピン留め)はインストールに接続されていない。
**対処**: `pyproject.toml` の `[project]` に集約し、ルート `setup.py` を削除。`S2MFD/setup.py`(物理プロファイル)はそのまま(ルート削除で名前の紛らわしさは解消)。

### 1.5 移流の中心差分と格子ペクレ数 →【指摘のみ・別課題】
`physics_core.py:70-74` は移流を純中心差分(`drr2`/`dth2`)で離散化。デフォルト設定で格子ペクレ数 Pe = uΔr/η ≈ 1.9 と、格子振動が出る古典的閾値 Pe=2 の直下にある。GA が u0 を増やす/η を下げる方向に振ると Pe>2 に入り、検知機構がないままチェッカーボードノイズや発散が起こり得る。
**対処(今回)**: NaN/発散検知の追加(1.6)で発散は捕捉。風上化・フラックスリミタ導入は物理挙動(実効拡散)が変わるため別課題として残す。`physics_core.py:67-68` に非保存形の別実装がコメントアウトで残っており、離散化の未解決の分岐として記録。

### 1.6 異常検知の欠如 →【今回修正】
NaN・発散チェックが皆無。発散したランも `tend`(20万日、~1.2×10⁵ ステップ)まで NaN を書き続ける。GA では致命的(不安定パラメタの個体が計算資源を浪費)。
**対処**: `main_loop` に周期的な NaN/振幅チェックを追加し、検知時は明示的に停止・報告。

### 1.7 CFL 条件 →【議論の結果、式は現状維持】
`simulation.py:54-69` の拡散制限は `dt ≤ 0.8·min(Δr, rΔθ)²/(2η)`。厳密な2次元限界は `1/(2η(1/Δr²+1/(rΔθ)²))` で、min()² 式はセルが等方に近いと限界を最大2倍過大評価する。ただし **η はスカラー**であり、現行 128×128 格子は Δr ≪ rΔθ(約6倍)のため差は 1〜2%、安全係数 0.8 で完全にカバーされる(2026-08-19 ユーザーと議論し現状維持を決定)。
**対処**: 前提(Δr ≪ rΔθ)を示すコメントを1行追加するのみ。数値は不変。将来 ix/jx を等方セルに近づける変更をする場合は再考のこと。極付近の `−ηq/(r²sin²θ)` 項(現行で余裕1桁)、Ω効果・α源のレートも dt 制約には含まれていないことを併記。
