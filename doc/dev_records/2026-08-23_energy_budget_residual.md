# エネルギー収支の残差の正体 (2026-08-23)

## 結論

引き継ぎ文書 (`handover_2026-08-23.md`) の未解決 1 番、
**「エネルギー収支の残差 -0.005 〜 -0.016 (入力の 10-25 パーセント)」は
未計上の物理項ではなく、収支式の左辺 dE_B/dt を落としていたためだった。**

時間微分を入れると、残差は Q_Lambda 比で **1e-5 〜 2e-4** になる。
原論文が明記している精度 0.001 より小さい。

| ラン | 入力/Q_L | dE_B/dt の最大 | 旧: 残差 (dE/dt を落とす) | 新: 残差 (dE/dt 込み) |
|---|---|---|---|---|
| v2_kin  | 0.008 | 0.0023 | 0.0013 | 0.000022 |
| v2_a125 | 0.008 | 0.0025 | 0.0019 | 0.000013 |
| v2_a250 | 0.029 | 0.0133 | 0.0090 | 0.000054 |
| v2_a500 | 0.091 | 0.0470 | 0.0330 | 0.000117 |

(いずれも Q_Lambda 比。両端 20 パーセントを除いた区間の平均。)

alpha_0 が大きいほど残差が大きく見えていたのは、磁場の成長が速くて
dE_B/dt が大きいからであって、精度が悪いからではない。

## どうやって分けたか

### 1. 時系列で dE_B/dt を入れる

`dynamo.npz` の `hist` には E_B と 8 つの Q 項が毎出力で入っている。
E_B を時間微分して

    miss = (Q_L^Omega + Q_L^M - Q_eta) - dE_B/dt

を測ると、入力比で 0.1-0.2 パーセントまで落ちた。

### 2. 残った 0.1-0.2 パーセントが差分の打ち切り誤差かを見る

2 次の中心差分と 4 次の局所多項式当てはめで比べた。

| ラン | 2 次差分 | 4 次当てはめ |
|---|---|---|
| v2_a125 | 0.00118 | 0.00121 |
| v2_a250 | 0.00173 | 0.00175 |
| v2_a500 | 0.00121 | 0.00124 |
| v2_kin  | 0.00224 | 0.00224 |

**縮まない。** 後処理の差分誤差ではない。

### 3. 時間刻みに比例するかを見る (時間積分誤差か)

同じ状態から dt を 1/2, 1/4, 1/8 にして 1 ステップの残差を測った。

| dt [s] | 残差/入力 |
|---|---|
| 167.45 | 0.00944 |
| 83.72  | 0.00944 |
| 41.86  | 0.00944 |
| 20.93  | 0.00944 |

**dt に依存しない。** 時間積分誤差でもない。

### 4. 格子を振る (空間離散化の不整合か)

解析的な流体場と磁場を与えて 1 ステップだけ進め、残差を
「4 項の絶対値の和」で規格化した。

| 格子 | 残差/規模 | 収束次数 |
|---|---|---|
| 54x36   | +0.01199 | - |
| 72x48   | +0.00690 | 1.92 |
| 108x72  | +0.00319 | 1.91 |
| 144x96  | +0.00186 | 1.88 |
| 216x144 | +0.00088 | 1.84 |
| 288x192 | +0.00053 | 1.79 |
| 432x288 | +0.00026 | 1.71 |

**2 次で消える。** つまり未計上の物理項ではなく、**診断とカーネルの
離散化のずれ**である。診断の Q_eta は正定値形

    Q_eta = int dV eta/varpi^2 (grad(varpi B_Phi))^2 / 4pi

で、誘導カーネルは発散形の拡散演算子を使う。連続では部分積分で厳密に
等しいが、離散では境界項と差分の非可換性の分だけずれる。

### 5. 磁場の SLD フィルタは寄与しない

フィルタの有無で残差は 1e-6 の桁まで同じ (108x72 / 216x144 / 432x288)。
SLD は勾配リミタなので滑らかな場では発動しない。よって

    dE_B/dt = Q_L^Omega + Q_L^M - Q_eta - Q_SLD

の Q_SLD は本設定では実質ゼロで、Rempel の式 (22) をそのまま使ってよい。

## 教訓

**残差を読むときは、ゼロと仮定した項が本当にゼロかを先に確かめる。**
これは 2026-08-23 の失敗パターン A (「その数字に何が入っているか確かめて
いない」) と同じ型で、以下と並ぶ:

- 配列の max をゴーストセル込みで取った
- Q_L^Omega を Omega_0 込みで評価した (解析的にゼロの項の離散残差が
  本物の信号の 8 倍だった)
- 振幅を永年ドリフト込みで測った

今回は逆向きで、**本当は大きい項をゼロと仮定した**。定常だと思い込んで
いたが、磁場は成長中だった。`d/dt` を見る、という対策がそのまま効く。

また失敗パターン D (「今回の修正で取り切れたと思わない」) の観点では、
`poloidal_mag` の修正後に残っていた -0.007 〜 -0.016 を「未説明の残差」
として書き残しておいたのは正しかった。**「閉じた」と宣言していたら、
今回の追い込みはしていない。**
