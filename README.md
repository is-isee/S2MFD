# S2MFD
Solar/Stellar Mean Field Dynamo code

---
## Installation

```bash
git clone https://github.com/is-isee/S2MFD.git
cd S2MFD
```

## Quick Start

You can run a simulation with the default parameters in `S2MFD/parameters/defaults.py`:
```python
import S2MFD
S2MFD.run_simulation()
```
