DynamoProblem

class S2MFD.inference.problem.DynamoProblem(parameter_file: str, obs_seconds: ndarray, obs_ssn: ndarray, index_start: int, index_end: int, mode: str, initial_Bph: ndarray, initial_Aph: ndarray, stage1_params: dict = None, spinup_years: float = 80.0, until_minimum: bool = True, alpha: float = 0.9, fitness_kind: str = 'standard')[source]

Bases: object

GA の評価器: evaluator(params) -> fitness。

Variables:

  • parameter_file (str) – シミュレーション設定 (S2MFD.Cfg に渡すパス)

  • obs_ssn (obs_seconds,) – 40日間隔に内挿済みの観測時系列 (observations.Observations の seconds / ssn)

  • index_end (index_start,) – 推定窓の観測インデックス範囲 [index_start, index_end]

  • mode (str) – ‘u0’ (Step 1: 子午面流) または ‘s0’ (Step 2: α効果)

  • stage1_params (dict, optional) – mode=’s0’ のとき必須。Step 1 で推定した u0 係数 {‘as_u’, ‘ae_u’, ‘a1_u’, ‘a2_u’, ‘a4_u’}

  • initial_Aph (initial_Bph,) – スピンアップの初期磁場 (observations.load_initial_field() 等)

  • spinup_years (float) – スピンアップの最低年数 (論文では 80 年)

  • alpha (float) – 適応度の重み (論文では 0.9)

適応度を返す。

fitness_kind=’standard’: F = alpha*相関 - (1-alpha)*NMSE (論文式 3.1) fitness_kind=’period’: F = -周期MSE (ダルトンミニマム用、論文式 4.2)

数値的に破綻した個体 (NaN 発散など) は -inf を返す。
