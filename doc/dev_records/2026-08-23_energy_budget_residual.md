# エネルギー収支の残差の正体 (2026-08-23)

## 結論

引き継ぎ文書 (`handover_2026-08-23.md`) の未解決 1 番、
**「エネルギー収支の残差 -0.005 〜 -0.016 (入力の 10-25 パーセント)」は
未計上の物理項ではなく、収支式の左辺 dE_B/dt を落としていたためだった。**

時間微分を入れると、残差は Q_Lambda 比で **1e-5 〜 2e-4** になる。
原論文が明記している精度 0.001 より小さい。

| ラン | 入力/Q_L | dE_B/dt の最大 | 旧: 残差 (dE/dt を落とす) | 新: 残差 (dE/dt 込み) |
|---|---|---|---|---|
| v2_kin  | 0.008 | 0.0023 | 0.0013 | 0.000022 |
| v2_a125 | 0.008 | 0.0025 | 0.0019 | 0.000013 |
| v2_a250 | 0.029 | 0.0133 | 0.0090 | 0.000054 |
| v2_a500 | 0.091 | 0.0470 | 0.0330 | 0.000117 |

(いずれも Q_Lambda 比。両端 20 パーセントを除いた区間の平均。)

alpha_0 が大きいほど残差が大きく見えていたのは、磁場の成長が速くて
dE_B/dt が大きいからであって、精度が悪いからではない。

## どうやって分けたか

### 1. 時系列で dE_B/dt を入れる

`dynamo.npz` の `hist` には E_B と 8 つの Q 項が毎出力で入っている。
E_B を時間微分して

    miss = (Q_L^Omega + Q_L^M - Q_eta) - dE_B/dt

を測ると、入力比で 0.1-0.2 パーセントまで落ちた。

### 2. 残った 0.1-0.2 パーセントが差分の打ち切り誤差かを見る

2 次の中心差分と 4 次の局所多項式当てはめで比べた。

| ラン | 2 次差分 | 4 次当てはめ |
|---|---|---|
| v2_a125 | 0.00118 | 0.00121 |
| v2_a250 | 0.00173 | 0.00175 |
| v2_a500 | 0.00121 | 0.00124 |
| v2_kin  | 0.00224 | 0.00224 |

**縮まない。** 後処理の差分誤差ではない。

### 3. 時間刻みに比例するかを見る (時間積分誤差か)

同じ状態から dt を 1/2, 1/4, 1/8 にして 1 ステップの残差を測った。

| dt [s] | 残差/入力 |
|---|---|
| 167.45 | 0.00944 |
| 83.72  | 0.00944 |
| 41.86  | 0.00944 |
| 20.93  | 0.00944 |

**dt に依存しない。** 時間積分誤差でもない。

### 4. 格子を振る (空間離散化の不整合か)

解析的な流体場と磁場を与えて 1 ステップだけ進め、残差を
「4 項の絶対値の和」で規格化した。

| 格子 | 残差/規模 | 収束次数 |
|---|---|---|
| 54x36   | +0.01199 | - |
| 72x48   | +0.00690 | 1.92 |
| 108x72  | +0.00319 | 1.91 |
| 144x96  | +0.00186 | 1.88 |
| 216x144 | +0.00088 | 1.84 |
| 288x192 | +0.00053 | 1.79 |
| 432x288 | +0.00026 | 1.71 |

**2 次で消える。** つまり未計上の物理項ではなく、**診断とカーネルの
離散化のずれ**である。診断の Q_eta は正定値形

    Q_eta = int dV eta/varpi^2 (grad(varpi B_Phi))^2 / 4pi

で、誘導カーネルは発散形の拡散演算子を使う。連続では部分積分で厳密に
等しいが、離散では境界項と差分の非可換性の分だけずれる。

### 5. 磁場の SLD フィルタは寄与しない

フィルタの有無で残差は 1e-6 の桁まで同じ (108x72 / 216x144 / 432x288)。
SLD は勾配リミタなので滑らかな場では発動しない。よって

    dE_B/dt = Q_L^Omega + Q_L^M - Q_eta - Q_SLD

の Q_SLD は本設定では実質ゼロで、Rempel の式 (22) をそのまま使ってよい。

## 入れたもの

- `tests/test_conservation.py::TestMagneticEnergyBudgetIdentity`

  - 54x36 -> 108x72 で残差が 1/2.5 以下 (2 次収束の確認)

## 教訓

**残差を読むときは、ゼロと仮定した項が本当にゼロかを先に確かめる。**
これは 2026-08-23 の失敗パターン A (「その数字に何が入っているか確かめて
いない」) と同じ型で、以下と並ぶ:

- 配列の max をゴーストセル込みで取った
- Q_L^Omega を Omega_0 込みで評価した (解析的にゼロの項の離散残差が
  本物の信号の 8 倍だった)
- 振幅を永年ドリフト込みで測った

今回は逆向きで、**本当は大きい項をゼロと仮定した**。定常だと思い込んで
いたが、磁場は成長中だった。`d/dt` を見る、という対策がそのまま効く。

また失敗パターン D (「今回の修正で取り切れたと思わない」) の観点では、
`poloidal_mag` の修正後に残っていた -0.007 〜 -0.016 を「未説明の残差」
として書き残しておいたのは正しかった。**「閉じた」と宣言していたら、
今回の追い込みはしていない。**

# 続き: 残り 2 つの収支式 (20) (21) も調べた

E_B が閉じたので、同じやり方で E_Omega と E_M も検証した。**両方とも
問題があった。**

## (20) E_Omega: Omega_0 の混入。Q_L^Omega とまったく同じ罠

E_Omega = int (1/2) rho0 varpi^2 (Omega_0 + Omega_1)^2 の時間微分は

    Omega_0 int rho0 varpi^2 d(Omega_1)/dt  +  int rho0 varpi^2 Omega_1 d(Omega_1)/dt

で、第 1 項は Omega_0 * dL/dt に比例するので**全角運動量保存から解析的に
厳密ゼロ**。ところが離散ではゼロにならず、Omega_0 が大きいので本物の
信号を飲み込む。緩和済み状態 (m108x72_cs030) の実測:

    Omega_0 の項  +0.0297 Q_Lambda   <- 本来ゼロ
    Omega_1 の項  +0.0007 Q_Lambda   <- 本物

時系列 (`run_paris/budget_check.py --relax`) でも同じ:

| ラン | t[yr] | 残差 (E_Omega を使う) | 残差 (E_DR を使う) | 残差 (E_M) |
|---|---|---|---|---|
| m108x72_cs030 | 39.9 | 0.18048 | 0.00442 | 0.01094 |
| m144x96_cs030 | 24.9 | 0.36563 | 0.00226 | 0.00450 |
| m216x144_cs030 | 9.3 | 1.33989 | 0.00931 | 0.01009 |
| s288x192_cs030 | 14.7 | 0.01174 | 0.00046 | 0.00124 |
| long80_cs030 | 79.8 | 0.05062 | 0.00429 | 0.01175 |

**左辺は必ず `differential_rotation_energy` (Omega_1 だけ) で評価する。**
`EnergyBudget.budget_residuals` の docstring に警告を入れた。

解析的な状態での収束 (`TestRotationAndMeridionalEnergyBudgets`):

| 格子 | E_Omega を使う | E_DR を使う |
|---|---|---|
| 54x36 | +0.528 | +0.00202 |
| 108x72 | +0.535 | +0.00072 |
| 216x144 | +0.540 | +0.00028 |

E_DR なら 2 次弱で消える。E_Omega では**まったく消えない**
(離散残差なので解像度を上げても Omega_0 倍が残る)。

## (21) E_M: Q_B はアネラスティック近似を仮定している

圧力勾配と重力の仕事を実測して分解した (緩和済み状態、cs=0.30):

    圧力勾配 -int v.grad p1     +0.1677 Q_Lambda
    重力     int v.rho1 g       -0.4715
    遠心力                      +0.4222  (診断 Q_C = +0.4268)
    残り (移流+幾何+粘性+人工拡散) -0.1184
    合計 dE_M/dt                -0.0000  (定常)

厳密な関係は (背景が多方性 p0 ∝ rho0^gamma なので厳密に):

    int v.(-grad p1 + rho1 g) dV = -Q_B + int (p1/rho0) div(rho0 v) dV

最後の項は div(rho0 v) = 0 のときだけ落ちる。**本実装は音速抑制した
圧縮性なのでゼロではない。** 解析的な (バランスしていない) 状態で確かめると

    圧力+重力の仕事 + Q_B   -5.8689 Q_Lambda
    int (p1/rho0) div(rho0 v) -5.8632 Q_Lambda    <- 0.1 パーセントで一致

緩和した解では div(rho0 v) が小さいのでこの項は -0.0001 Q_Lambda しかない。
それでも残差が 0.0118 Q_Lambda 残るが、これは離散化で、解像度とともに消える
(各解像度の緩和済み状態で実測):

| 格子 | 圧力+重力 | -Q_B | 差 | 音響項 | 残差 (E_M) |
|---|---|---|---|---|---|
| 108x72 | -0.3037 | -0.4099 | +0.1062 | -0.0001 | +0.0118 |
| 144x96 | -0.3601 | -0.4131 | +0.0529 | -0.0001 | +0.0056 |
| 216x144 | -0.4021 | -0.4099 | +0.0078 | -0.0020 | +0.0007 |
| 288x192 | -0.4073 | -0.4117 | +0.0044 | +0.0000 | +0.0012 |

## まとめ: 3 つの収支式は連続極限ですべて閉じる

| 収支式 | 108x72 での残差 | 288x192 での残差 | 主な誤差源 |
|---|---|---|---|
| (20) E_Omega (E_DR で評価) | 0.0044 | 0.00046 | 離散化 |
| (21) E_M | 0.0109 | 0.00124 | 離散化 (圧力と重力の部分積分) |
| (22) E_B | 1.3e-5 (ダイナモ実測) | - | 離散化 (Q_eta の正定値形) |

**論文の格子 108x72 では (21) の残差が 0.011 で、原論文が明記している
精度 0.001 の 10 倍ある。** これは本プロジェクトの中心的な主張
(N_r=108 は未収束) と整合する独立の証拠になる。

## 教訓の追加

**「小さい摂動が大きな背景に乗る量」は 3 回目。**

1. `Q_L^Omega` を `Omega_0 + Omega_1` で評価した (2026-08-22)
2. トーショナル振動の振幅を永年ドリフト込みで測った (2026-08-23)
3. `dE_Omega/dt` を `Omega_0 + Omega_1` で評価した (2026-08-23、今回)

いずれも「背景項が解析的に消えるなら、手で消してから評価する」で防げる。
**このコードで Omega が出てきたら、まず Omega_0 の項が解析的にゼロに
なるかを確かめる習慣にする。**
