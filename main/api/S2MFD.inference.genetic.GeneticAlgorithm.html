class S2MFD.inference.genetic.GeneticAlgorithm(evaluator, param_spec, population_size, config=None, initial_population=None)[source]

Bases: object

遺伝的アルゴリズム本体。

Parameters:

  • evaluator (callable) – evaluator(params: dict) -> float (適応度)。並列実行のため picklable であること (クロージャ不可。dataclass 等を推奨)。

  • param_spec (dict[str, tuple[float, float]]) – 推定パラメタ名 → 初期集団の一様分布範囲 (min, max)。 例 (u0推定): {‘as_u’: (500, 900), …, ‘a0_s’: (40, 65)}

  • population_size (int) – 個体数 (論文では 30)。

  • config (GAConfig, optional)
