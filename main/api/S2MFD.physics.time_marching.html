time_marching

S2MFD.physics.time_marching(Bph, Aph, dt, cfg, grid, setup)[source]

Perform time marching for the magnetic field.

Parameters:

  • Bph (numpy.ndarray) – Longitudinal magnetic field

  • Aph (numpy.ndarray) – Longitudinal vector potential

  • dt (float) – Time step

  • cfg (S2MFD.Cfg) – Configuration object. cfg.exact_arithmetic = True を設定すると 参照実装とビット一致する低速版を使う (既定は高速版)。

  • grid (object) – Object containing grid information

  • setup (object) – Object containing setup information

Returns:

  • Bphm : Updated longitudinal magnetic field

  • Aphm : Updated longitudinal vector potential

Return type:

tuple of numpy.ndarray

Notes

既定の高速版は除算を逆数の乗算に置き換え、numba の fastmath を有効にする。 参照実装との差は 1 substep あたり相対 ~2e-16 (倍精度 1 ULP 程度) で、 物理的な意味を持たない丸め誤差の範囲にある。ビット一致が必要な場合は cfg.exact_arithmetic = True を指定するか time_marching_reference() を直接呼ぶこと。
