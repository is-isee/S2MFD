## 見つかった設定ミス: 磁場の下部境界条件

**Rempel (2006) §2.2:**

> The boundary condition is A = B_Phi = 0 at the pole and dA/dtheta = B_Phi = 0
> at the equator, which selects the dipole symmetry for the solution;
> **B_Phi vanishes at both radial boundaries**, while A vanishes at the inner
> boundary, and the poloidal field is assumed to be radial at the top boundary.

つまり下部境界 (r = 0.65 R) は **A = 0 かつ B_Phi = 0**。

ところが `rempel06_paper.py` は `defaults.py` の
`boundary_condition_type = 'vertical'` を継承しており、下部が**完全導体**
(A = 0, d(rB_Phi)/dr = 0) になっていた。

**論文どおりの `'R06'` は `boundary_condition.py` に実装済みだったが、
どのパラメタファイルからも使われていなかった。** 実装した本人 (自分) が
配線し忘れていた。

`'R06'` のコメント自身が「深部は磁気拡散が 3 桁小さいのでここの扱いが効く」
と書いている (eta_c = 1e5 m^2/s は対流層の 1/1000)。

**対照実験を投入した** (`run_paris/launch_bc_r06.sh`)。走っている `v2_kin` が
`'vertical'` の対照そのものなので、同じ設定で境界条件だけ変えた
`bcR06_kin` を 1 本出せば差が見える。

# 続き: 磁場の下部境界条件は**論文に合わせない**ことにした

対照実験 `bcR06_kin` (108x72、論文どおり下部 B_Phi = 0) は**発散した**。

    t[yr]   max|Bph|[T]   Bph@0.735R赤道[G]
     1.60      0.29         85
     3.20      0.28        304      <- 0.735R の値は正常 (符号反転もする)
     4.80      0.40        411
     6.40      1.09        572
     8.00      3.06        582
     9.60      8.86        500
    11.20     25.75        345
    12.80     76.45        119
    13.07     92.03       -156

**0.735 RSUN 赤道の B_phi は最後まで正常** (600 G 程度で符号反転もする) なのに、
**全体の max だけが 4.4 年目から 1.1 年で倍増する指数成長**をした。局所的。

## 物理: 内部境界としては対称 (零フラックス) の方が正しい

下部境界 r = 0.65 RSUN は**放射層の内部**で、実際の太陽には境界がない。
放射層は良導体なので、下りてきたトロイダル磁場は**蓄えられる**べきである。

- `B_Phi = 0` (反対称) は境界を**トロイダル磁束と磁気エネルギーの吸い込み**に
  する。∂_r B_phi が大きくなり拡散フラックスが外へ抜ける
- `d(rB_Phi)/dr = 0` (対称) は拡散フラックスがゼロ = **閉じた境界**。
  A = 0 と合わせて B_r もゼロなので両成分とも閉じる

**論文自身が「B_Phi だけは closed boundary condition ではない」と書いている**
(§3.2: "We use the appropriate closed boundary conditions for all variables
except for B_Phi; however, the resistive flux across the **upper** boundary
turns out to be negligible")。上部については無視できると言っているが、
**下部については何も言っていない。**

2026-08-23 に検証した式 (22) の収支が Q_Lambda 比 1e-5 - 1e-4 で閉じるのは
**対称 (閉じた) 境界だから**である。R06 にすると境界フラックス項が要る。

## 数値: 論文の格子では境界層が 1 セルに入らない

`B_Phi = 0` で固定すると、深部の小さい eta (eta_c = 1e5 m^2/s = 1e9 cm^2/s)
が作る抵抗層の厚みは sqrt(eta t)。

| 格子 | 底の Δr | 抵抗層 (1 年) | 層/Δr |
|---|---|---|---|
| 108x72 | 0.00386 R | 0.00255 R | **0.66** |
| 216x144 | 0.00195 R | 0.00255 R | 1.31 |
| 288x192 | 0.00147 R | 0.00255 R | 1.74 |

**論文の格子では 1 セルに入らない。** Rempel の MacCormack は交互風上/風下で
暗黙の数値散逸を持つので通っている可能性がある。

216x144 で安定かを確かめる対照 (`bc216_R06` / `bc216_vertical`) を投入した
(`run_paris/launch_bc_r06_hires.sh`)。安定なら「論文の格子では解けない
境界層だった」と言え、N_r = 108 が未収束という主張の独立な証拠が増える。

## 決定

**本番は対称 (`boundary_condition_type = 'vertical'`) のままにする。**
ユーザ (堀田) の判断: 「最終的には B_phi は対称が下部境界としては良い」。
論文からの逸脱として、上の根拠と数字を記録に残す。
